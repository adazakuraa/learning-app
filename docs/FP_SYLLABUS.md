## FP01 お金と人生設計の基本
1. お金の教養とは何か（目的と限界、FP資格との関係）
2. ライフプランとキャッシュフロー表（人生の三大支出：住宅・教育・老後）
3. 家計の見える化：収入・支出・貯蓄率とバランスシート
4. 貯める・減らす・守る・増やすの順番（優先順位）

## FP02 家計管理と貯蓄
1. 固定費と変動費、家計簿とキャッシュレスの管理
2. 生活防衛資金（緊急予備資金）の考え方
3. 目的別の貯め方（先取り貯蓄・口座の分け方）
4. 預金の種類と預金保険制度（1,000万円の保護）
5. ポイント・クレジットカード・電子マネーの賢い使い方

## FP03 金利・インフレ・お金の時間価値
1. 金利と複利・単利、72の法則
2. インフレとデフレ：お金の価値は変わる
3. 現在価値と将来価値（終価・現価・年金現価）
4. 実質金利と、物価・為替・日銀の役割

## FP04 社会保険
1. 日本の社会保障の全体像（公助・共助・自助）
2. 健康保険と高額療養費・傷病手当金・出産手当金
3. 介護保険と高齢者の費用
4. 雇用保険（失業給付・育児休業給付）
5. 労災保険と、働くときの法律の基礎

## FP05 年金
1. 公的年金の仕組み（国民年金・厚生年金・3階建て）
2. 年金額の目安・受給開始時期の繰上げ繰下げ
3. 遺族年金・障害年金（もしものときの年金）
4. 私的年金：iDeCo・企業年金・国民年金基金
5. 老後に必要な額の考え方（「2,000万円問題」の読み方）

## FP06 民間保険（リスク管理）
1. リスクと保険の基本（保険は「万一」に備えるもの）
2. 生命保険：定期・終身・収入保障・医療保険の考え方
3. 損害保険：火災・地震・自動車・個人賠償責任
4. 必要保障額の考え方と、入りすぎ・不足の見直し
5. 保険のしくみ（保険料の中身、解約返戻金、共済）

## FP07 税金
1. 税金の全体像（国税・地方税、直接税・間接税）
2. 所得税のしくみ（給与所得・控除・累進課税）
3. 住民税・社会保険料と、手取りの計算
4. 年末調整・確定申告・医療費控除・ふるさと納税
5. 消費税・自動車税・固定資産税など身近な税

## FP08 住まい
1. 持ち家か賃貸か：考え方と費用の比較
2. 住宅ローンの仕組み（金利タイプ、返済方式、総返済額）
3. 住宅購入の費用・諸費用・住宅ローン控除
4. 賃貸契約・更新・保証・トラブルの基礎
5. 不動産の登記・売買・相場の基礎

## FP09 資産運用の基礎
1. 投資とは何か：リスクとリターン、分散投資
2. 株式・債券・投資信託・ETF・REITの特徴
3. 長期・積立・分散：新NISAとiDeCoの活用
4. 投資の費用（手数料・信託報酬・税金）
5. 行動経済学：人はなぜ損をするか（損失回避・群集心理）
6. 為替・外貨・金・暗号資産の基礎とリスク

## FP10 ローン・信用・詐欺
1. クレジットカードとリボ払い・分割払いの落とし穴
2. 借入・消費者金融・奨学金と返済の考え方
3. 信用情報とクレジットスコア
4. 詐欺・悪質商法・投資詐欺の見分け方（SNS・ロマンス・詐欺的投資）
5. 借金で困ったとき：相談窓口・債務整理・自己破産

## FP11 教育・結婚・育児・仕事とお金
1. 教育費と奨学金・教育資金の貯め方
2. 結婚・出産・育児のお金と給付金
3. 転職・退職・フリーランスと、保険・税金・年金の手続き
4. 副業・起業の税金と社会保険
5. 夫婦のお金・離婚・パートナーとのお金の話し方

## FP12 相続・贈与・老後・介護
1. 相続の基礎（法定相続人・相続分・遺言・遺留分）
2. 相続税・贈与税のしくみと、生前贈与・非課税の特例
3. 遺言・エンディングノート・成年後見・家族信託
4. 老後の住まい・介護施設・在宅介護の費用
5. 親が亡くなった後の手続き（死亡届・年金・口座・名義変更）

## FP13 お金の教養の総まとめ
1. 経済ニュースの読み方（GDP・物価・景気・金利）
2. お金の考え方：価値観・幸福・ライフステージごとの優先順位
3. 年齢別チェックリスト（20代・30代・40代・50代・60代以降）
4. 公的な相談窓口と、信頼できる情報源・専門家の選び方（FP・税理士・社労士）

## メモ
- 数値（税率・金額・制度）は「2026年時点」と明記し、変わりうる点は注意書きを付けます。
- 特定の商品・金融機関の推奨はしません（一般的な仕組みと考え方の解説に限定）。
- FP資格試験の対策ではなく、大人の教養として広く浅くではなく「判断できる」深さを目指します。
