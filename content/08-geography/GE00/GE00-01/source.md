# 地理とは・学ぶ意味

## この科目の概要

地理では、地図の見方、世界と日本の地形・気候、資源や産業、人口や都市、そして各地域の特徴を学びます。

## この科目で学ぶこと

| 章 | 内容 |
|---|---|
| 第1章 | 地図と地球の基礎 |
| 第2章 | 世界の地形と気候 |
| 第3章 | 世界の資源・農業・経済 |
| 第4章 | 世界の人口と都市 |
| 第5章 | アジア |
| 第6章 | ヨーロッパ・ロシア |
| 第7章 | アフリカ・南北アメリカ・オセアニア |
| 第8章 | 日本の地形と自然 |
| 第9章 | 日本の地域と産業 |
| 第10章 | 現代世界の地理的課題 |

## 学ぶ意味

### 世界の「なぜ」がわかる

なぜこの国は豊かなのか、なぜ食べ物の値段が変わるのか。地形や気候、資源から考えると理由が見えてきます。

### 災害に備えられる

日本の地形や気候の特徴を知ることは、地震や水害などの災害から身を守ることにつながります。

### 旅行やビジネスに役立つ

時差、気候、その地域の産業や文化。知っていると、旅行や仕事の計画が立てやすくなります。

## こんなときに役立つ

- ハザードマップで自分の住む場所を確かめるとき
- 輸入品の値上がりなど、経済ニュースを見るとき
- 海外旅行の計画を立てるとき

## 学び方のコツ

- **地図を見ながら**学ぶ
- 地形・気候・産業を「だからこうなる」でつなげる
