# お金の教養とは

## まず覚えること

- お金の教養の目的は、**お金の不安を減らし、自分で判断できる**ようになること。
- FP（ファイナンシャルプランナー）の分野は、**家計・保険・年金・税金・住まい・投資・相続**など、人生のお金全体。
- 「うまい話」より、**仕組みを知って比べる**ことが一番の防御。

## この科目で学ぶこと

| 分野 | 主な内容 |
|---|---|
| 人生設計・家計 | ライフプラン、貯蓄、金利とインフレ |
| もしもへの備え | 社会保険、年金、民間保険 |
| 税金 | 所得税・住民税、年末調整、確定申告 |
| 住まい | 持ち家と賃貸、住宅ローン |
| 増やす | 投資、NISA、iDeCo |
| 守る | ローン、詐欺対策 |
| 引き継ぐ | 相続、贈与、介護 |

## FPとは

**ファイナンシャルプランナー**は、家計全体を見て、人生の目標に合わせたお金の計画を手伝う専門家です。この科目は資格試験の対策ではなく、大人の教養として、**自分で判断するための基礎**を学びます。

## お金の判断の基本姿勢

- **仕組みを理解してから**選ぶ。わからない商品は買わない。
- **手数料・税金・リスク**を必ず確認する。
- 制度はよく変わるので、**最新の公式情報**を確認する習慣をつける。

---

*制度や金額は2026年時点の一般的な内容で、改正されることがあります。実際の判断は、最新の公式情報や専門家（税務署・年金事務所・FPなど）で確認してください。特定の商品をすすめるものではありません。*
