# 家族が亡くなった後の手続き

## まず覚えること

- **死亡届は7日以内**（葬儀社が代行することが多い）。
- 年金・健康保険の手続き、**預金口座は凍結**されるので葬儀費用の準備に注意。
- 遺族は**葬祭費・埋葬料**（数万円）や**遺族年金**を請求できる。

## 主な手続きと期限

| 期限 | 手続き |
|---|---|
| 7日以内 | 死亡届、火葬許可 |
| 10日〜14日以内 | 年金の受給停止、健康保険・介護保険の資格喪失、世帯主の変更 |
| 3か月以内 | 相続放棄（借金が多い場合） |
| 4か月以内 | 準確定申告 |
| 10か月以内 | 相続税の申告 |
| 2〜5年以内 | 葬祭費・埋葬料、遺族年金、生命保険金の請求 |

## 預金口座

金融機関が亡くなったことを知ると口座は**凍結**されます。遺産分割前でも、**一定額（1金融機関150万円まで等）は引き出せる**制度があります。

## 便利な制度

- **おくやみコーナー**：多くの市区町村で、手続きをまとめて案内してくれる。
- **法定相続情報証明制度**：法務局で一覧図を作ると、何度も戸籍を集めずに済む。

---

*制度や金額は2026年時点の一般的な内容で、改正されることがあります。実際の判断は、最新の公式情報や専門家（税務署・年金事務所・FPなど）で確認してください。特定の商品をすすめるものではありません。*
