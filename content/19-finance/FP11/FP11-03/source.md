# 転職・退職・フリーランス

## まず覚えること

- 退職したら、**健康保険**（任意継続・国民健康保険・家族の扶養）と**国民年金**の手続きを**14日以内**に。
- 退職した翌年の**住民税**は前年の所得で来るので、お金を残しておく。
- フリーランスは**保障が薄い**ので、生活防衛資金を多めに、iDeCoや小規模企業共済などで自分で備える。

## 退職後の手続き

| 手続き | 選択肢 |
|---|---|
| **健康保険** | ①会社の保険を**任意継続**（最長2年）②**国民健康保険**③家族の**扶養**に入る |
| **年金** | 国民年金に切り替え（次の会社にすぐ入るなら不要） |
| **雇用保険** | ハローワークで失業給付の手続き |
| **税金** | 年の途中で退職し再就職しないなら、**確定申告**で税金が戻ることがある |

## 会社員とフリーランスの違い

| | 会社員 | フリーランス |
|---|---|---|
| 社会保険料 | 会社が半分負担 | 全額自分 |
| 傷病手当金・失業給付 | あり | 原則なし |
| 年金 | 厚生年金あり | 国民年金のみ |
| 税金 | 年末調整 | 確定申告。経費を引ける |

フリーランスは、**青色申告**で最大65万円の控除が受けられるなど、税金の工夫もできます。
