# 日本の社会保障の全体像

## まず覚えること

- 社会保険は**医療・年金・介護・雇用・労災**の5つ。
- 会社員は**会社と半分ずつ**保険料を払う（労災は会社が全額）。
- 民間保険は、**公的保険で足りない部分**を補うもの。まず公的保険を知る。

## 5つの社会保険

| 保険 | 備えるリスク |
|---|---|
| **医療保険（健康保険）** | 病気・けが |
| **年金保険** | 老後・障害・死亡 |
| **介護保険** | 介護が必要になったとき（40歳から加入） |
| **雇用保険** | 失業、育児・介護での休業 |
| **労災保険** | 仕事中・通勤中のけがや病気 |

## 会社員と自営業の違い

| | 会社員・公務員 | 自営業・フリーランス |
|---|---|---|
| 医療 | 健康保険（会社の） | 国民健康保険 |
| 年金 | 厚生年金＋国民年金 | 国民年金のみ |
| 雇用・労災 | あり | 原則なし |
| 病気で休んだとき | 傷病手当金あり | 原則なし |

自営業は公的な保障が薄いぶん、**自分で備える**必要が大きくなります。
