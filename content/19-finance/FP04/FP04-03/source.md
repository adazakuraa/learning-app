# 介護保険

## まず覚えること

- **40歳から加入**して保険料を払い、主に**65歳以上**で介護が必要になったら使える。
- 使うには**市区町村に申請して「要介護認定」**を受ける。
- サービスの自己負担は**原則1割**（所得により2〜3割）。相談先は**地域包括支援センター**。

## 介護保険のしくみ

| | 第1号被保険者 | 第2号被保険者 |
|---|---|---|
| 年齢 | 65歳以上 | 40〜64歳 |
| 使えるとき | 原因を問わず介護が必要 | 老化に関係する特定の病気（16種類）による場合 |

## 使い方

1. 市区町村の窓口か、**地域包括支援センター**に相談
2. 申請 → 調査 → **要支援1〜2、要介護1〜5**の認定
3. **ケアマネジャー**がケアプランを作る
4. デイサービス、訪問介護、施設などを利用

## お金の目安

介護にかかる費用は、平均で**月約9万円、期間は約5年**という調査があります（生命保険文化センター）。介護費用の上限を設ける**高額介護サービス費**もあります。
