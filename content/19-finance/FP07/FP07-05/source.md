# 確定申告のやり方

## まず覚えること

- 期間は原則**2月16日〜3月15日**。**e-Tax**（マイナンバーカードとスマホ）で自宅から出せる。
- 会社員でも必要：**副業の所得が20万円超**、**年収2,000万円超**、2か所以上から給料など。
- すると得：**医療費控除、ふるさと納税（6か所以上やワンストップ特例を使わないとき）、住宅ローン控除の1年目**。

## 確定申告が必要な人

| 人 | 理由 |
|---|---|
| 自営業・フリーランス | 年末調整がない |
| 会社員で**副業などの所得が20万円を超える** | 給料以外の所得の申告 |
| 年収2,000万円を超える会社員 | 年末調整の対象外 |
| 不動産の家賃収入や、株を売った利益（特定口座の源泉なし）がある | |

※住民税は、副業所得が20万円以下でも申告が必要です。

## 申告するとお金が戻る（還付）もの

| 控除 | 条件の目安 |
|---|---|
| **医療費控除** | 家族の医療費が年**10万円**（所得200万円未満は所得の5%）を超えた |
| **セルフメディケーション税制** | 対象の市販薬を年1.2万円超買った（医療費控除と選択） |
| **ふるさと納税** | ワンストップ特例を使わない、6か所以上に寄付 |
| **住宅ローン控除（1年目）** | 2年目からは年末調整でできる |
| **雑損控除** | 災害や盗難の被害 |

還付の申告は、**翌年1月から5年間**さかのぼってできます。

## やり方

国税庁の「**確定申告書等作成コーナー**」で、画面の案内に沿って入力すると計算してくれます。マイナポータルと連携すると、医療費や保険料のデータを自動で取り込めます。
