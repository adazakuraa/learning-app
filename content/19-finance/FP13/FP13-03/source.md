# 年代別のお金のチェックリスト

## まず覚えること

- **20代**：生活防衛資金、NISAで少額の積立、クレジットカードの延滞をしない。
- **30〜40代**：保険と住まいの見直し、教育資金、iDeCoも検討。
- **50代〜**：老後資金の確認、年金の受け取り方、親の介護・相続の準備。

## 年代別チェックリスト

| 年代 | やっておきたいこと |
|---|---|
| **20代** | 手取りと支出を把握／生活防衛資金を貯める／NISAで少額積立／奨学金の返済計画／カードは一括払い |
| **30代** | 結婚・出産のお金／保険を必要な分だけ／住宅の判断／教育資金の積立 |
| **40代** | 老後資金の見積もり／iDeCoの活用／住宅ローンの見直し／親と介護・相続の話 |
| **50代** | ねんきん定期便で年金額を確認／退職金の確認／60代以降の働き方／支出の見直し |
| **60代〜** | 年金の受け取り時期／退職金の運用は慎重に／介護・相続・エンディングノート |

## どの年代でも

- 年に1回、**家計とお金の計画を見直す**
- **詐欺**に注意（年代ごとに手口が違う）
- 制度の変更を確認する

---

*制度や金額は2026年時点の一般的な内容で、改正されることがあります。実際の判断は、最新の公式情報や専門家（税務署・年金事務所・FPなど）で確認してください。特定の商品をすすめるものではありません。*
