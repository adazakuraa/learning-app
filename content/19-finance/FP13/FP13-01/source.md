# 経済ニュースの読み方

## まず覚えること

- **GDP**は国全体のもうけの大きさ。**物価（CPI）**は生活費の上がり方。
- 物価が上がると**日銀が金利を上げ**、金利が上がると**ローンが重く、預金の利息が増える**。
- ニュースは**「自分の家計にどう影響するか」**に置きかえて読む。

## よく出てくる指標

| 指標 | 意味 | 家計への影響 |
|---|---|---|
| **GDP** | 国内で生み出された価値の合計 | 増えると給料も上がりやすい |
| **消費者物価指数（CPI）** | 物の値段の変化 | 上がると生活費が増える |
| **実質賃金** | 物価を考えた給料の価値 | マイナスなら生活は苦しくなる |
| **政策金利** | 日銀が決める金利 | ローン・預金金利に影響 |
| **為替レート** | 円とドルなどの交換比率 | 円安で輸入品が値上がり |
| **日経平均株価** | 日本の代表的な株価の指数 | 投資・年金の運用に影響 |

## つながりの例

**円安** → 輸入品・エネルギーが値上がり → **物価が上がる** → **日銀が金利を上げる** → **住宅ローン（変動）の返済が増える**

## 読み方のコツ

- 「上がった・下がった」だけでなく、**なぜ**と**誰に影響するか**を考える。
- 1日の動きに一喜一憂せず、**長い流れ**を見る。
