# 相談先と信頼できる情報

## まず覚えること

- お金の相談は**内容によって専門家が違う**（税金は税理士、年金は社労士・年金事務所、法律は弁護士）。
- 無料の公的窓口（**税務署、年金事務所、消費生活センター188、法テラス**）を活用する。
- 金融商品をすすめる相談は、**手数料のしくみ**（誰からお金をもらっているか）を確認する。

## 相談先の使い分け

| 悩み | 相談先 |
|---|---|
| 税金・確定申告 | **税務署**、税理士 |
| 年金 | **年金事務所**（ねんきんダイヤル）、社会保険労務士 |
| 借金・トラブル | **法テラス**、弁護士、司法書士 |
| 契約・詐欺 | **消費者ホットライン188**、警察（#9110） |
| 家計全体・ライフプラン | FP（ファイナンシャルプランナー） |
| 介護 | **地域包括支援センター** |

## FPに相談するとき

- **独立系（相談料を払う）**と、**金融機関・保険代理店（商品の販売手数料で収入を得る）**がある。
- 無料相談は、商品の販売が前提のことが多い。
- 資格は**CFP®、1級・2級FP技能士**など。

## 信頼できる情報源

**金融庁、国税庁、日本年金機構、厚生労働省、消費者庁、J-FLEC（金融経済教育推進機構）**などの公式サイト。SNSの「必ずもうかる」情報は疑ってかかります。
