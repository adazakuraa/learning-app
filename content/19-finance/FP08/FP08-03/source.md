# 家を買うときのお金

## まず覚えること

- 物件価格のほかに**諸費用（新築で3〜5%、中古で6〜8%程度）**がかかる。
- **頭金**は多いほど利息が減るが、貯金を出し切らない。
- **住宅ローン控除**で、年末のローン残高の0.7%が最長13年、税金から差し引かれる（条件あり）。

## 主な諸費用

| 費用 | 内容 |
|---|---|
| 仲介手数料 | 中古物件など。物件価格の約3%＋6万円＋消費税が上限 |
| 登記費用 | 登録免許税、司法書士報酬 |
| ローンの手数料・保証料 | |
| 火災保険・地震保険 | |
| 税金 | 不動産取得税、印紙税 |
| 引っ越し・家具 | |

## 住宅ローン控除

- 年末のローン残高の**0.7%**が、所得税（引ききれなければ住民税の一部）から引かれる。
- 新築は**最長13年**。省エネ性能などで上限額が違う。
- 1年目は**確定申告**、2年目からは年末調整。
- 制度は改正が多いので、**購入する年のルール**を確認。

## 買った後のお金

固定資産税、マンションなら**管理費・修繕積立金**、一戸建ても**自分で修繕費を積み立てる**（10〜15年ごとに外壁・屋根など）。

---

*制度や金額は2026年時点の一般的な内容で、改正されることがあります。実際の判断は、最新の公式情報や専門家（税務署・年金事務所・FPなど）で確認してください。特定の商品をすすめるものではありません。*
