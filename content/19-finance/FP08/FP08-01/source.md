# 持ち家か賃貸か

## まず覚えること

- 持ち家と賃貸の**生涯コストは条件次第で大差ないことも多い**。「どちらが得」より「どちらが合うか」。
- 持ち家は**資産になるが、動きにくく、修繕費や固定資産税**がかかる。
- 賃貸は**身軽だが、老後も家賃が続き、高齢になると借りにくい**ことがある。

## 比べるポイント

| | 持ち家 | 賃貸 |
|---|---|---|
| 費用 | ローン、固定資産税、修繕費、管理費 | 家賃、更新料 |
| 自由度 | 引っ越しにくい | 引っ越しやすい |
| 老後 | ローン完済後は住居費が下がる | 家賃が続く。高齢で借りにくいことも |
| 資産 | 家・土地が残る（価値は変わる） | 残らない |
| リスク | 災害、地域の価値の下落、金利上昇 | 家賃の値上げ |

## 判断の目安

- 転勤が多い、家族構成が変わりそう → 賃貸が柔軟
- 長く住む地域が決まっている、老後の住居費を下げたい → 持ち家も選択肢
- どちらでも、**住居費は手取りの25〜30%程度まで**が無理のない目安

---

*制度や金額は2026年時点の一般的な内容で、改正されることがあります。実際の判断は、最新の公式情報や専門家（税務署・年金事務所・FPなど）で確認してください。特定の商品をすすめるものではありません。*
