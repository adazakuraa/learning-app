# 金利・為替と日銀の役割

## まず覚えること

- **日本銀行**は物価の安定のために、**政策金利**を上げ下げする。
- 金利が**上がる**と、ローンの返済が増え、預金の利息は増える。
- **円安**は輸入品が値上がりし、**円高**は輸入品が安くなる。

## 金利の動きと家計

| 金利が上がると | 金利が下がると |
|---|---|
| 預金の利息が増える | 預金の利息が減る |
| 住宅ローン（変動）の返済が増える | ローンの返済が減る |
| 債券の価格は下がる | 債券の価格は上がる |

## 為替

| | 円安（1ドル＝100円→150円） | 円高（150円→100円） |
|---|---|---|
| 輸入品・海外旅行 | 高くなる | 安くなる |
| 輸出企業 | もうかりやすい | 厳しくなる |
| 外貨建て資産 | 円での価値が増える | 円での価値が減る |

## 日銀の役割

- 物価の安定（年2%の物価上昇を目標）
- 政策金利の調整、お金の量の調整
- 日本は長くマイナス金利でしたが、**2024年に解除**し、金利のある時代に戻りつつあります。
