# FP・お金の教養とは・学ぶ意味

## この科目の概要

FP・お金の教養では、家計、貯蓄、保険、年金、税金、住まい、投資、ローン、相続まで、大人なら知っておきたいお金の基礎を、ひととおり学びます。

## この科目で学ぶこと

| 章 | 内容 |
|---|---|
| 第1章 | お金と人生設計の基本 |
| 第2章 | 家計管理と貯蓄 |
| 第3章 | 金利・インフレ・お金の時間価値 |
| 第4章 | 社会保険 |
| 第5章 | 年金 |
| 第6章 | 民間保険 |
| 第7章 | 税金 |
| 第8章 | 住まい |
| 第9章 | 資産運用の基礎 |
| 第10章 | ローン・信用・詐欺 |
| 第11章 | 人生の出来事とお金 |
| 第12章 | 相続・贈与・老後・介護 |
| 第13章 | お金の教養の総まとめ |

## 学ぶ意味

### お金の不安が減る

年金や老後資金、保険。仕組みを知ると、漠然とした不安が、具体的な計画に変わります。

### 損をしにくくなる

手数料の高い商品、必要以上の保険、詐欺。仕組みを知ることが、いちばんの防御です。

### 使える制度を逃さない

NISA、iDeCo、高額療養費、児童手当。知らないと使えない制度がたくさんあります。

## こんなときに役立つ

- 保険やローンを選ぶとき
- 税金や年金の手続きをするとき
- 貯金や投資の計画を立てるとき

## 学び方のコツ

- 自分の家計に**当てはめながら**学ぶ
- 制度は変わるので、最新の公式情報も確認する
