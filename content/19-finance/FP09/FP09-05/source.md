# iDeCo（個人型確定拠出年金）

## まず覚えること

- iDeCoは**掛金が全額所得控除**、**運用益は非課税**、**受け取るときも控除**がある、税金面で最も有利な制度の一つ。
- その代わり、**原則60歳まで引き出せない**。老後のためのお金と割り切って使う。
- 掛金の上限は働き方で違う（会社員で企業年金なしなら**月2.3万円**など）。

## 3つの税金のメリット

| タイミング | メリット |
|---|---|
| 掛けるとき | 掛金が**全額所得控除**（所得税・住民税が安くなる） |
| 運用中 | 利益に**税金がかからない** |
| 受け取るとき | 一時金は**退職所得控除**、年金は**公的年金等控除**が使える |

例：年収500万円の会社員が月2万円（年24万円）掛けると、**年に約4.8万円**税金が安くなります（所得税10%＋住民税10%の場合）。

## 掛金の上限（2026年時点の月額）

| 働き方 | 上限 |
|---|---|
| 自営業・フリーランス | 6.8万円（国民年金基金などと合算） |
| 会社員（企業年金なし） | 2.3万円 |
| 会社員（企業年金あり）・公務員 | 2万円（会社の掛金との合計に上限あり） |
| 専業主婦・主夫 | 2.3万円 |

**2027年から上限の引き上げ**（会社員は企業年金と合わせて月6.2万円など）が予定されています。

## 注意点

- **60歳まで引き出せない**（教育費や住宅資金には使えない）。
- 口座の管理手数料が毎月かかる（月171円〜）。
- 専業主婦・主夫や所得の少ない人は、所得控除の効果が小さい。

## NISAとの使い分け

| | NISA | iDeCo |
|---|---|---|
| 引き出し | いつでも | 原則60歳から |
| 掛金の所得控除 | なし | あり |
| 向いているお金 | 教育・住宅・老後の幅広い目的 | 老後専用 |

いつでも使えるNISAを基本に、余裕があれば節税効果の大きいiDeCoを足す、という考え方が一般的です。
