# 新NISA

## まず覚えること

- NISAで得た利益は**非課税**（通常は約20%の税金がかかる）。
- 年間の上限は**つみたて投資枠120万円＋成長投資枠240万円＝360万円**、生涯の上限は**1,800万円**。
- 非課税の期間は**無期限**で、売った分の枠は**翌年に復活**する。

## 新NISAのしくみ（2024年〜）

| | つみたて投資枠 | 成長投資枠 |
|---|---|---|
| 年間の上限 | 120万円 | 240万円 |
| 買えるもの | 国が選んだ長期・積立向けの投資信託 | 株式、投資信託など |
| 生涯の上限 | 合計1,800万円（うち成長投資枠は1,200万円まで） | |

- 対象：**18歳以上**、1人1口座
- 非課税期間：**無期限**
- いつでも売れる（売った分の枠は翌年に復活）

## 使い方のコツ

- まずは**つみたて投資枠**で、手数料の安いインデックスファンドを毎月積立。
- 損失が出ても、ほかの口座の利益と相殺（損益通算）できない点に注意。
- 金融機関は1年に1回変えられる。**ネット証券**は商品が多く手数料も安い傾向。
