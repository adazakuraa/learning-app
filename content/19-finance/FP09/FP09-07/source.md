# 行動経済学：人はなぜ損をするのか

## まず覚えること

- 人は**損を、同じ額の得より約2倍強く感じる**（損失回避）。そのため損を確定できず、売り時を誤りやすい。
- **みんなが買っているから買う**（群集心理）と、高値でつかみやすい。
- 心のくせを防ぐには、**ルールを先に決めて自動化する**（積立設定・リバランスの時期を決める）。

## 代表的な心のくせ

| くせ | 内容 | お金の失敗の例 |
|---|---|---|
| **損失回避** | 損は得より強く痛む | 下がった株を「戻るまで」持ち続ける |
| **群集心理** | 周りに合わせる | ブームの銘柄を高値で買う |
| **現在バイアス** | 今の満足を優先 | 貯金を先延ばし、リボ払い |
| **アンカリング** | 最初に見た数字に引きずられる | 「定価◯万円が今だけ半額」 |
| **確証バイアス** | 信じたい情報だけ集める | SNSの成功談だけを信じる |
| **サンクコスト** | もう払ったお金を惜しむ | 合わない保険を「もったいない」と続ける |

## 対策

- **積立を自動化**して、タイミングを考えない。
- 年に1回だけ、資産の割合を見直す（**リバランス**）。
- 「今だけ」「あなただけ」「絶対もうかる」と言われたら、**一度立ち止まる**。
