# 社会学とは・学ぶ意味

## この科目の概要

社会学は、家族、学校、会社、メディアなど、人と人が集まってできる「社会」の仕組みと、それが個人に与える影響を考える学問です。

## この科目で学ぶこと

| 章 | 内容 |
|---|---|
| 第1章 | 社会学とは何か |
| 第2章 | 社会の構造 |
| 第3章 | 不平等と階層 |
| 第4章 | 逸脱と社会統制 |
| 第5章 | 相互作用と日常生活 |
| 第6章 | メディアと情報社会 |
| 第7章 | 宗教・文化・アイデンティティ |
| 第8章 | 社会学と哲学の接点 |

## 学ぶ意味

### 「当たり前」を見直せる

常識や習慣は、時代や社会によって違います。社会学の目を持つと、当たり前だと思っていたことの理由が見えてきます。

### 悩みを社会の問題として考えられる

個人の悩みに見えることも、社会の構造が関係していることがあります。自分を責めすぎずに、仕組みから考えられます。

### 情報社会を賢く生きる

メディアが人の考えにどう影響するかを知ると、ニュースやSNSとの付き合い方が変わります。

## こんなときに役立つ

- 格差や差別のニュースを考えるとき
- SNSやメディアの影響を考えるとき
- 職場や地域での人間関係を理解したいとき

## 学び方のコツ

- 用語を**身近な場面**に当てはめる
- 「それは社会のどんな仕組みから来ている？」と問う
