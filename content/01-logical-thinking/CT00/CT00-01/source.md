# ロジカルシンキングとは・学ぶ意味

## この科目の概要

ロジカルシンキング（批判的思考）は、主張や情報を、根拠と論理にもとづいて評価し、自分の頭で筋道を立てて考えるための技術です。

## この科目で学ぶこと

| 章 | 内容 |
|---|---|
| 第1章 | 批判的思考 |
| 第2章 | 論理の基本 |
| 第3章 | 誤謬 |
| 第4章 | 認知バイアスと自己批判 |
| 第5章 | 情報を評価する |
| 第6章 | 議論を分析・評価する |
| 第7章 | 実践的な批判的思考 |

## 学ぶ意味

### だまされにくくなる

ネットのうわさ、広告、もっともらしい統計。主張と根拠を分けて見るくせがつくと、根拠の弱い話に気づけます。

### 自分の思い込みに気づける

人は誰でも、信じたいことを信じる傾向（認知バイアス）を持っています。仕組みを知ると、自分の判断を見直せます。

### 話し合いが前に進む

相手の主張を正しく理解し、どこで意見が分かれているかを整理できると、議論が感情的なぶつかり合いになりにくくなります。

## こんなときに役立つ

- ニュースやSNSの情報を見るとき
- 仕事で提案したり、反論したりするとき
- 大きな買い物や進路など、重要な決断をするとき

## 学び方のコツ

- 用語を覚えるより、**身近な例に当てはめて**考えてみる
- 自分の意見にも同じ物差しを当てる
