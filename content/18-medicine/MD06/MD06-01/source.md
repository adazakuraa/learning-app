# 発疹とかゆみ

発疹（皮膚の赤み、ぶつぶつ、水ぶくれ）は、皮膚だけの問題か、**全身の病気のサイン**かを見分けることが大切です。

## 救急車（119）を考えるサイン

- 発疹と一緒に**息苦しさ、顔や唇の腫れ、ぐったり、ふらつき**（アナフィラキシー）
- **発熱と、押しても消えない赤紫の斑点（紫斑）**（髄膜炎菌などの重症感染）
- **ぐったり、意識がぼんやり**、高熱を伴う発疹
- **口・目・性器の粘膜のただれ**と、皮膚が**やけどのようにむける**、発熱（**重症薬疹**：スティーブンス・ジョンソン症候群など）。新しい薬を飲み始めて**1〜3週間後**に多い。
- 痛みの強い赤みが急速に広がり、水ぶくれ、黒ずむ（壊死性軟部組織感染症）

## 今日中に受診したいサイン

- 発熱を伴う発疹
- **薬を飲み始めてから**出た発疹（**その薬の服用を中止してよいか、受診して相談**）
- 急速に広がる、痛みがある
- 水ぶくれが増える
- 目の充血、のどの痛み、リンパ節の腫れを伴う
- **妊娠中**の発疹（風疹など、胎児に影響する感染症のことがある）
- 子どもの発疹で、機嫌が悪い、高熱が続く

## 発疹の主な原因

| 分類 | 病気 | 特徴 |
|---|---|---|
| **皮膚の炎症** | **湿疹（皮膚炎）** | かゆみ、赤み、カサカサ。洗剤、金属、植物などが原因（接触皮膚炎）、アトピー性皮膚炎 |
| | **じんま疹** | 赤く盛り上がり、数時間で跡を残さず消える。強いかゆみ（次の単元） |
| | **薬疹** | 全身に赤い発疹。薬の開始後数日〜数週間 |
| **感染症** | **麻疹（はしか）** | 発熱3〜4日、咳、目の充血の後に発疹。感染力が非常に強い（空気感染）。**受診前に必ず電話連絡** |
| | **風疹** | 軽い発熱、発疹、首のリンパ節の腫れ。**妊娠初期の感染は、胎児に影響（先天性風疹症候群）** |
| | **水痘（水ぼうそう）** | かゆみのある水ぶくれが次々に。成人は重症化しやすい |
| | **伝染性紅斑（りんご病）** | 頬が赤くなる。妊婦への感染に注意 |
| | **手足口病** | 手のひら、足の裏、口の中の水ぶくれ。乳幼児に多い |
| | **突発性発疹** | 乳児。高熱が3日続き、解熱と同時に発疹 |
| | **溶連菌感染症** | のどの痛み、発熱、発疹 |
| | **帯状疱疹** | 体の片側に、帯状に、痛みと水ぶくれ（第5章） |
| | **梅毒** | 手のひら・足の裏にも出る発疹など（第5章） |
| **川崎病** | 主に5歳以下 | 5日以上の発熱、目の充血、唇の赤み・イチゴ舌、発疹、手足の腫れ、首のリンパ節腫脹。**早期治療が必要**（第9章） |
| **虫** | 虫刺され、疥癬 | かゆみ、夜に悪化 |

## 麻疹（はしか）は特に注意

- 空気感染で、同じ部屋にいただけで感染する。
- **MRワクチン（麻しん風しん混合）を2回受けていない大人**は感染リスクがある。
- 疑う場合は、**そのまま受診せず、先に医療機関に電話**し、受診方法の指示を受ける。
- 母子手帳や記録で、予防接種歴を確認しておく（第13章）。

## 自宅でできること

- **掻かない**。爪を短く切る。
- **冷やす**（かゆみが強いとき、保冷剤をタオルで包んで）。
- **保湿**（入浴後すぐに保湿剤）。肌に刺激になる石けん、洗剤、衣類を避ける。
- **原因の可能性があるもの（新しい洗剤、化粧品、食べ物、薬）**を中止して、記録する。
- 市販の抗ヒスタミン薬（かゆみ）、ステロイド外用薬（弱いもの）。**顔や広範囲、長期の使用は受診して相談**。
- 写真を撮っておくと、経過の説明に役立つ（発疹は受診時に消えていることがある）。
