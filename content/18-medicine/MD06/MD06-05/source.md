# かまれた・刺された・異物

## まず覚えること

- ハチに刺されて**全身の症状**（じんま疹・息苦しさ・ふらつき）が出たら119。
- ヘビにかまれたら**安静にしてすぐ119**。傷口を吸う・切る・強く縛るはしない。
- 目に薬品が入ったら**すぐ流水で15分以上洗い**、眼科へ。

## かまれた・刺された

| 相手 | すること |
|---|---|
| **ハチ** | その場を離れる。針が残れば払うように取る。冷やす。全身症状なら119 |
| **ヘビ（マムシなど）** | 動かず安静、すぐ119。写真を撮れれば撮る |
| **犬・猫・人** | よく洗って受診。**猫の咬み傷**は小さくても感染しやすい |
| **クラゲ** | こすらず**海水**で洗い流す。全身症状なら119 |
| **マダニ** | 無理に取らず皮膚科へ。数週間は発熱に注意 |

## 異物

| 場所 | すること |
|---|---|
| **目** | こすらず水で洗う。薬品は**15分以上**流水。取れなければ眼科 |
| **耳・鼻（子ども）** | 無理に取らず耳鼻咽喉科 |
| **刺さったもの（大きい）** | 抜かずに固定して119 |
| **魚の骨** | ご飯を丸のみしない。取れなければ耳鼻咽喉科 |

子どもの誤飲は第9章、窒息は第12章で扱います。
