# 子どもの事故：誤飲・窒息・転落・溺水

## まず覚えること

- **ボタン電池・磁石・薬・強い洗剤・たばこ**を飲み込んだら、無理に吐かせずすぐ受診（119も）。
- 迷ったら**中毒110番**（大阪 072-727-2499、24時間）。
- **ぶどう・ミニトマトは4つ切り、ピーナッツは4歳まで与えない**。浴槽に水を残さない。

## 誤飲

| 飲み込んだもの | 対応 |
|---|---|
| **ボタン電池** | 数時間で食道に穴があく。**すぐ受診** |
| **磁石（2個以上）** | 腸をはさんで穴があく。すぐ受診 |
| **大人の薬、たばこ** | 吐かせず受診・中毒110番 |
| **洗剤・漂白剤・灯油** | 吐かせず受診 |
| 少量の石けん・クレヨンなど | 多くは心配ない。相談を |

容器や残りを持って受診します。

## 窒息

- 声が出ない、咳もできない → **119**と、背中を強く叩く・胸やおなかを突き上げる（方法は第12章）。
- 予防：小さく切る、食べながら走らせない、直径4cm未満の物を手の届く所に置かない。

## 転落・溺水

- ベランダに足場になる物を置かない、窓に補助錠。
- **浴槽の残り湯は抜く**、子どもだけで入浴させない。溺水は**音もなく**起こる。

## 頭を打ったとき

すぐ泣いて普段どおりなら様子見。**ぐったり、何度も吐く、けいれん**は119（第2章の5）。
