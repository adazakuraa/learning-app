# 子どもの発熱・けいれん・咳

## 発熱

| 年齢 | 対応 |
|---|---|
| **生後3か月未満** | **38℃以上は、重い感染症のことがあり、すぐ受診（夜間も）** |
| 3か月〜1歳 | 元気がない、哺乳が減るなら受診。**生後数か月は、受診しやすい**ようにしておく |
| 1歳以上 | 元気、水分がとれる → 家で様子。**3日（72時間）以上続く**、高熱、**悪化**なら受診 |

### 高熱が続くとき

- **川崎病**（主に5歳以下）：**5日以上の発熱**、目の充血、唇の赤み、イチゴ舌、発疹、手足の腫れ、首のリンパ節。**心臓の冠動脈に瘤ができる**ことがあり、**早期の治療（免疫グロブリン）**が重要。**発熱が4〜5日続いたら**小児科で相談。
- **尿路感染症**：**乳幼児の原因不明の発熱**で多い。**尿検査**。
- **突発性発疹**：3〜4日の高熱の後、解熱して発疹。機嫌は比較的良い。

## 熱性けいれん

- **生後6か月〜5歳**の、**発熱時**に起こる、**全身が硬直・ガクガク**するけいれん。**約10人に1人**が経験する。
- 多くは**5分以内に自然に止まる**。後遺症は通常残さない。

### 起きたら

1. **慌てず、時間を測る**。
2. **平らな場所で、横向き**に寝かせる。**口に物を入れない**（舌を噛むのを防ぐつもりでも、窒息や損傷のもと）。
3. **体を揺さぶらない**。抱きしめない。
4. **けいれんの様子**（左右差、目の向き）を観察、**動画で撮る**と診察に役立つ。

### 119を呼ぶ

- **5分以上**続く
- 止まっても**意識が戻らない**、繰り返す
- **初めて**のけいれん、**1歳未満**、**6歳以上**
- **片側のみ**、手足の麻痺
- **首が硬い、嘔吐を繰り返す**

## 咳・呼吸の症状

| 病気 | 特徴 | 受診の目安 |
|---|---|---|
| **クループ** | **犬が吠えるような咳（犬吠様咳嗽）**、声がかれる、**吸うときのヒューという音**。夜に悪化 | **息を吸うとき苦しそう、安静時もヒュー**ならすぐ救急 |
| **急性喉頭蓋炎** | **よだれ、前かがみ、声が出ない、高熱**。急速に悪化。**無理に口を開けて見ない** | **救急**（ワクチン（Hib）で激減） |
| **細気管支炎（RSウイルス）** | 2歳未満、鼻水→咳、ゼーゼー、**哺乳が減る**。乳児で重症化 | **呼吸が速い、哺乳できない、無呼吸**は救急 |
| **喘息** | ゼーゼー、夜間や運動時の咳 | 発作で**話せない、肋骨の間がへこむ**ならば救急。普段の**吸入薬・発作時の薬** |
| **百日咳** | **長引く、激しい咳き込み、「ヒュー」という吸気音**、乳児は無呼吸。**ワクチン**で予防 | |
| **肺炎・気管支炎** | 発熱、湿った咳、呼吸が速い | |
| **異物の誤嚥** | **突然むせた後**の咳・ゼーゼー | **救急**（ピーナッツなど） |

### 呼吸が苦しそうなサイン

- **呼吸が速い**（1分間に、乳児 **60回以上**、幼児 **40回以上**が目安）
- **肋骨の間・のどの下・みぞおちが、息を吸うときにへこむ**（陥没呼吸）
- **鼻の穴が広がる、うなる**
- **顔や唇が紫色**
- **ゼーゼーして話せない**

## 吐く・下痢

- **嘔吐・下痢が続き、おしっこが出ない、ぐったり**：**脱水**。
- **嘔吐が緑色（胆汁）、血が混じる**：緊急。**腸の閉塞（腸重積、腸回転異常）**の可能性。
- **乳児が、数分おきに激しく泣き、休む、いちご色の粘血便**：**腸重積**。**緊急**（第4章）。

### 脱水の予防

- 少量ずつ、**スプーンで、数分おき**に経口補水液。
- **一気に飲ませる**と吐く。
- **哺乳は続ける**。
