# 医療のかかり方：かかりつけ医・薬・医療費

## かかりつけ医を持つ

- **普段の健康相談、軽い病気、慢性疾患の管理**ができ、**必要なときに専門医・大病院へ紹介**してくれる医師。
- **メリット**：**経過や薬を把握**してもらえる、**夜間や急変時の相談**、**重複した検査・薬を避けられる**。
- **大病院（特定機能病院など）は、紹介状がないと、追加料金**（選定療養費）がかかることが多い。**まず、診療所・中小病院**へ。

## 診療科の選び方（迷ったとき）

| 症状 | 目安 |
|---|---|
| よくわからない、全身の症状 | **内科、総合診療科** |
| 頭痛、しびれ、めまい | **内科、脳神経内科**、緊急は救急 |
| 胸、息苦しさ | **内科（循環器・呼吸器）**、緊急は救急 |
| おなか | **内科（消化器）**、**外科** |
| 皮膚 | **皮膚科** |
| 目、耳・鼻・のど | **眼科、耳鼻咽喉科** |
| 排尿、性器 | **泌尿器科**、女性は**婦人科** |
| 骨・関節・腰 | **整形外科** |
| 心の不調 | **心療内科、精神科** |
| 子ども | **小児科** |
| 歯・口 | **歯科、口腔外科** |

**病院の窓口に「どの科か」を電話で聞く**のも、ごく普通のことです。**#7119**でも相談できます。

## 受診のコツ

- **「いつから、どんな症状か、きっかけ、変化、飲んだ薬、持病、アレルギー」**を**メモ**して持参。
- **写真・動画**（発疹、けいれん、便）。
- **聞きたいこと**を書いておく。**「次はいつ再受診か」「どうなったら再受診・救急か」**を必ず確認する。
- **「検査の結果」「診断の根拠」「他の可能性」**を聞いてよい。
- **お薬手帳**、**保険証（マイナ保険証）**。

## 薬の基礎

- **処方薬**は、**指示された量・期間**を守る。**抗菌薬（抗生物質）**は、**症状が良くなっても、医師の指示がなければ途中でやめない**（ただし**自己判断で、前の薬を使い回さない**）。
- **抗菌薬は、ウイルス（かぜ・インフルエンザ）には効かない**。**不要な使用は、耐性菌**の増加につながる。
- **副作用が出たら、自己判断で中止せず、薬剤師・医師に相談**（**息苦しさ、全身の発疹**などは、すぐ受診）。
- **市販薬**：**成分を確認**し、**同じ成分を重複**しない（総合感冒薬と解熱鎮痛薬）。**薬剤師に相談**。
- **サプリメント・健康食品**：**薬との相互作用**（セント・ジョーンズ・ワート、グレープフルーツ）。**「効く」という広告は、根拠が弱い**ことも。
- **ジェネリック医薬品（後発医薬品）**：**有効成分は同じで、安価**。
- **漢方**：**体質に合わせた処方**。**副作用**もあり、**医師・薬剤師と**。
- **お薬手帳**は**1冊に**。

## 医療費の仕組み（日本）

- **公的医療保険**：**窓口負担は原則3割**（**未就学児は2割**、**70歳以上は2〜3割**、**75歳以上は1〜3割**など）。
- **高額療養費制度**：**1か月の自己負担が一定額を超えたとき、超えた分が払い戻される**。**所得による上限**。**事前に「限度額適用認定証」（または、マイナ保険証の利用）**で、窓口の支払いを上限までにできる。
- **医療費控除**：**年間の医療費が一定額（10万円など）を超えたとき、確定申告で所得税・住民税が軽くなる**。
- **民間の医療保険**：**公的保険と高額療養費で、自己負担は限られる**ことを踏まえて、必要性を考える。
- **傷病手当金**：**会社員が、病気やケガで仕事を休み給与が出ない**とき、健康保険から支給される。

## セカンドオピニオン

- **診断や治療方針に迷う**、**大きな手術・がん治療**のとき、**別の医師の意見を聞く**制度。
- **主治医に、「セカンドオピニオンを聞きたい」と伝えれば、紹介状・検査データ**を用意してくれる。**失礼ではない**。**自費（保険外）**のことが多い。

## 信頼できる医療情報の探し方

- **信頼できる情報源**：**厚生労働省、国立がん研究センター「がん情報サービス」、日本の学会**の診療ガイドライン解説、**日本医師会**、**自治体、WHO、CDC**。
- **注意**：**個人のブログ、SNSの体験談、広告**（「奇跡の」「これだけで治る」）、**「医師が教えない」系**の動画。
- **確認する点**：**誰が書いたか、根拠（研究）はあるか、日付が新しいか、利益（商品販売）のためではないか**。
- **ネットの情報は、「診断」ではなく、「受診するときの参考」**にする。
