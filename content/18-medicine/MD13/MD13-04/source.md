# ワクチン

## まず覚えること

- ワクチンは**免疫に予行演習をさせる**しくみ。かかっても**重症化を防ぐ**効果も大きい。
- 大人が確認したいのは、**麻疹・風疹**の接種歴、**破傷風**、**65歳以上の肺炎球菌・帯状疱疹・インフルエンザ**。
- 副反応の多くは**腫れや発熱が数日で治まる**。重いアレルギーはまれ。

## 大人が確認したいワクチン

| ワクチン | ポイント |
|---|---|
| **麻疹・風疹（MR）** | 接種歴が不明なら抗体検査か接種。**妊娠を考える人とその家族**は特に |
| **破傷風** | けがの備え。約10年ごと |
| **インフルエンザ** | 毎年。高齢者・持病のある人・妊婦 |
| **肺炎球菌** | 65歳など対象年齢で |
| **帯状疱疹** | 50歳以上。65歳などは公費の対象（自治体で確認） |
| **HPV** | 子宮頸がんを防ぐ。接種の機会を逃した世代にも機会がある |
| **新型コロナ** | 高齢者・持病のある人 |

対象年齢や費用は変わるので、**自治体や厚生労働省の最新情報**を確認します。

## 子どもの定期接種

母子手帳で確認し、**決められた時期に**。ヒブ・肺炎球菌・五種混合・BCG・MR・水痘・日本脳炎・B型肝炎など。

## 安全性

- 「ワクチンが自閉症の原因」という説は**否定されています**。
- 定期接種で健康被害が起きたときは、**国の救済制度**があります。
