# 検査を知る：血液・画像・内視鏡

## 健康診断と、病気の検査

- **健診（健康診断）**：**症状のない人が、病気の早期発見、リスクの確認**のために受ける。
- **検診（がん検診など）**：**特定の病気**を見つけるための検査。
- **診断のための検査**：**症状がある人**が、**原因を調べる**ために受ける。

## 基本の検査

### 血液検査

| 項目 | 何を見るか |
|---|---|
| **血球（白血球、赤血球、ヘモグロビン、血小板）** | **感染、貧血、血液の病気** |
| **肝機能（AST、ALT、γ-GTP）** | 肝臓の障害、飲酒 |
| **腎機能（クレアチニン、eGFR）** | 腎臓の働き |
| **血糖、HbA1c** | **糖尿病**（HbA1cは**過去1〜2か月**の平均） |
| **脂質（LDLコレステロール、HDL、中性脂肪）** | **動脈硬化のリスク** |
| **尿酸** | **痛風** |
| **CRP** | **炎症**の程度 |
| **トロポニン** | **心筋の障害**（心筋梗塞） |
| **Dダイマー** | **血栓**の可能性（高いだけでは診断できない） |
| **腫瘍マーカー** | **がんの診断には使えず**、経過観察の補助。**検診目的では、通常推奨されない** |

### 尿検査

- **タンパク、血液、糖**、**感染（白血球、細菌）**。**腎臓病、糖尿病、尿路感染・結石**。

### 心電図

- **心臓の電気活動**。**不整脈、心筋梗塞**。**数分で、痛みなく**行える。**運動中のみ出る異常**は、**運動負荷・ホルター（24時間）心電図**。

## 画像検査

### X線（レントゲン）

- **骨、肺、お腹**。**短時間、安価**。**被ばくは少ない**（胸部1回は約0.06mSv。**日本の自然放射線は、1年で約2.1mSv**）。

### CT（コンピュータ断層撮影）

- **X線を使い、体の断面（輪切り）**を画像にする。
- **短時間（数秒〜数分）**で、**出血、骨折、肺・腹部の病気、血栓、がん**を調べられる。**救急で役立つ**。
- **造影剤**（ヨード）で、**血管や病変**を見やすくする。**アレルギー、腎機能、喘息、妊娠**に注意。
- **被ばく**：**胸部CTで約2〜7mSv、腹部で約10mSv**。**1回の被ばくで、がんのリスクは、ごくわずかに上がる**が、**必要な検査の利益のほうが大きい**。**不要な検査は避ける**。**妊娠の可能性**は必ず伝える。

### MRI

- **強い磁石と電波**で、**脳、脊髄、関節、骨盤内臓器、軟部組織**を詳細に見る。**被ばくはない**。
- **時間がかかる（15〜60分）、大きな音、狭い筒の中**（閉所恐怖症に注意）。
- **金属**：**心臓ペースメーカー、人工内耳、金属片**がある場合、**検査できない・制限**がある。**必ず申告**。**検査室に磁性体を持ち込まない**。
- **脳梗塞の早期**は、**CTでは見えにくく、MRIで分かる**。**脳出血は、CTで早く分かる**。

### 超音波（エコー）

- **音波**。**被ばくなし、ベッドサイドで、リアルタイム**。**腹部（肝臓、胆のう、腎臓）、心臓、甲状腺、乳房、妊娠中の胎児**。**空気や骨の裏は見えにくい**。

### 核医学（PET、シンチ）

- **微量の放射性薬剤**を注射して、**代謝の活発な場所（がんなど）**を調べる。**PET-CT**で**がんの広がり・転移、再発**の評価。**検診の人間ドック**にもあるが、**早期がんの見落とし**もあり、万能ではない。

## 内視鏡

- **胃カメラ（上部消化管内視鏡）**：**食道、胃、十二指腸**。**胃がん、食道がん、ピロリ菌関連**。**経鼻・経口、鎮静（眠らせる）**を選べることも。
- **大腸カメラ（下部消化管内視鏡）**：**大腸ポリープ、大腸がん**。**前処置（下剤）**が必要。**ポリープは、その場で切除**できる。
- **気管支鏡、膀胱鏡**など。

## 検査を受けるときの考え方

- **必要な検査**：**症状・診察から、診断が変わる、治療が変わる**場合。
- **偽陽性・偽陰性**：**異常でないのに「異常」と出る、異常があるのに見逃す**ことがある。**感度・特異度**。
- **「念のため」の検査（たくさん受けるほどよい）ではない**：**不要な追加検査、不安、負担**を招くことがある。
- **「異常なし」でも、症状が続く・悪化するときは、再受診**。
- **結果は、数字だけでなく**、**基準範囲**と**前回との比較**、**医師の説明**で。**基準範囲は、健康な人の95%が入る範囲で、少し外れても必ず病気とは限らない**。
