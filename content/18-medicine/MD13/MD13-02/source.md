# 検査の基本：血液・CT・MRIなど

## まず覚えること

- **CT**はX線で短時間に体の断面を撮る。**救急（出血・骨折）に強い**。少し被ばくがある。
- **MRI**は磁石で撮る。**脳・脊髄・関節に強く**、被ばくはないが時間がかかり、**金属に注意**。
- **超音波（エコー）**は被ばくがなく、その場ですぐ見られる。

## 主な画像検査

| 検査 | しくみ | 得意なもの | 注意 |
|---|---|---|---|
| **X線（レントゲン）** | X線 | 骨、肺 | 被ばくはわずか |
| **CT** | X線で断面 | 出血、骨折、肺、おなか | 被ばくがある。妊娠の可能性を伝える |
| **MRI** | 磁石と電波 | 脳、脊髄、関節 | 30分前後かかる。**ペースメーカーなど金属は必ず申告** |
| **超音波（エコー）** | 音波 | 心臓、おなか、胎児 | 被ばくなし |
| **内視鏡（胃カメラ・大腸カメラ）** | カメラを入れる | 胃・大腸のがん、ポリープ | ポリープはその場で取れる |

## 血液検査で見るもの（代表例）

| 項目 | わかること |
|---|---|
| 白血球・CRP | 炎症・感染 |
| ヘモグロビン | 貧血 |
| AST・ALT・γ-GTP | 肝臓 |
| クレアチニン・eGFR | 腎臓 |
| 血糖・HbA1c | 糖尿病 |
| LDLコレステロール | 動脈硬化のリスク |

## 検査の考え方

- 検査は**多ければ良いわけではない**。異常がないのに「異常」と出ることも（偽陽性）。
- 基準値から少し外れても、すぐ病気とは限らない。**前回との比較**が大事。
