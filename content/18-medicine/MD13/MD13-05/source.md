# 予防医学：生活習慣・慢性病・エビデンスの読み方

## 「病気になってから」より「ならないように」

日本人の**死因の上位**（がん、心疾患、脳血管疾患、老衰、肺炎）の多くは、**生活習慣が関係**します。**予防医学**は、**一次予防（発症を防ぐ）、二次予防（早期発見・早期治療＝検診）、三次予防（再発・悪化を防ぐ）**に分けられます。

## 生活習慣病：**症状がないまま進む**

### 高血圧

- **血圧が高い状態が続く**と、**血管が傷つき、脳卒中、心臓病、腎臓病**のリスクが上がる。
- **症状がほとんどない**ため、**「サイレントキラー」**。**家庭血圧の測定**が有効。
- **対策**：**減塩（1日6g未満が目標）、体重を減らす、運動、節酒、禁煙、カリウムを含む野菜・果物**。**必要なら降圧薬**。**自己判断で中止しない**。

### 糖尿病

- **血糖値が高い状態が続く**。**症状（のどが渇く、尿が多い、体重減少）**が出る頃には進んでいる。
- **合併症**：**網膜症（失明）、腎症（透析）、神経障害、心臓病・脳卒中**。
- **2型糖尿病**：**生活習慣＋遺伝**。**食事・運動で予防・改善**。**1型**は、自己免疫などで、**インスリンが必要**。
- **低血糖**：**冷や汗、ふるえ、動悸、意識がもうろう**。**糖尿病の薬・インスリン使用中の人**に。**ブドウ糖・砂糖を摂る**。**意識がなければ救急**。

### 脂質異常症

- **LDLコレステロール、中性脂肪が高い、HDLが低い**。**動脈硬化**。
- **食事（飽和脂肪酸を控える）、運動、薬（スタチンなど）**。

### 動脈硬化

- 血管の壁に脂肪がたまる。**心筋梗塞・脳梗塞・閉塞性動脈硬化症**の原因。
- **危険因子**：**高血圧、糖尿病、脂質異常症、喫煙、肥満、運動不足、家族歴、加齢**。**複数あるほど、リスクが掛け算で増える**。

## 効果の確かな生活習慣

| | 内容 |
|---|---|
| **禁煙** | **最も効果が大きい**。**やめるのに遅すぎることはない**。**受動喫煙も害**。**電子タバコ・加熱式**も、**ニコチンを含み、安全とは言えない** |
| **運動** | **週150分程度の中強度の有酸素運動（早歩き）＋筋トレ週2回**。**座りっぱなしを減らす** |
| **食事** | **野菜・果物・全粒穀物・魚・豆類、減塩、加工食品や砂糖入り飲料を控える**。**極端な食事制限は、続かない** |
| **体重** | **適正体重**（BMI 18.5〜25）。**急激な減量は、危険** |
| **飲酒** | **控える**（前の単元） |
| **睡眠** | **7時間前後**。**不足は、肥満・糖尿病・高血圧・うつのリスク** |
| **社会的なつながり、ストレスの管理** | **孤立は、健康リスク（喫煙に匹敵するという研究もある）** |

## 「健康情報」の見極め方：エビデンス

- **エビデンス（科学的根拠）の強さ**：
  1. **システマティックレビュー・メタ分析**（複数の研究をまとめる）
  2. **ランダム化比較試験（RCT）**：**薬・治療を受けるグループと、受けないグループをくじ引きで分けて比べる**。
  3. **観察研究（コホート、症例対照）**：**「相関」はわかるが、「因果」はわからない**。
  4. **症例報告、専門家の意見、動物実験・試験管内の実験**
  5. **個人の体験談**（**最も弱い**）
- **「〜を食べる人は長生き」**：**健康意識の高い人が食べている**（**交絡**）可能性。
- **「効いた」という体験談**：**自然に治った、プラセボ（思い込み）効果、たまたま**かもしれない。
- **相対リスクと絶対リスク**：**「リスクが2倍」**でも、**もとが1万人に1人なら、2人**。**絶対リスクの差**を見る。
- **有意差と、意味のある差**は違う。
- **広告・「奇跡」「医師が隠す」「ワンパターンの食材で完治」**：**警戒**。
- **ホメオパシー、多くのサプリメント、デトックス、「免疫力を高める」**などは、**有効性の十分な根拠がない**ものが多い。
- **がんの代替療法だけに頼る**ことで、**標準治療を受けず、命を縮める**例がある。**標準治療と並行しての相談**も、**主治医に伝える**。
