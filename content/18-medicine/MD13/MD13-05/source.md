# 予防医学：生活習慣と健康情報の読み方

## まず覚えること

- いちばん効果が大きい予防は**禁煙**。次に**運動・食事・体重・節酒・睡眠**。
- **高血圧・糖尿病・脂質異常症**は症状がないまま進み、脳卒中や心臓病の原因になる。健診で見つけて治療を続ける。
- 「〜を食べる人は長生き」は**相関であって因果とは限らない**。体験談や広告は根拠が弱い。

## 効果が確かな生活習慣

| 習慣 | 目安 |
|---|---|
| **禁煙** | がん・心臓病・脳卒中すべてのリスクが下がる。禁煙外来は保険が使える |
| **運動** | 早歩きなどを**週150分**＋筋トレ週2回 |
| **食事** | 野菜・果物・魚・豆、**減塩**、甘い飲み物と加工肉を控える |
| **体重** | BMI 18.5〜25未満 |
| **お酒** | 控えめに。飲まない人が健康のために飲む必要はない |
| **睡眠** | 7時間前後 |

## 症状のない病気

| 病気 | 目安 |
|---|---|
| **高血圧** | 家庭で135/85以上 |
| **糖尿病** | HbA1c 6.5%以上 |
| **脂質異常症** | LDLコレステロールが高い |

どれも**動脈硬化**を進め、**脳卒中・心筋梗塞**の原因になります。薬が必要なら自己判断でやめないこと。

## 健康情報の見分け方

- 根拠の強さ：**複数の研究のまとめ ＞ くじ引きで分けた試験 ＞ 観察研究 ＞ 体験談**
- 「リスク2倍」も、**もとの確率が小さければ増える数はわずか**。
- 「これだけで治る」「医者が教えない」「奇跡の」は疑う。
