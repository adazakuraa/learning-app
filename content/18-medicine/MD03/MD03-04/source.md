# 咳・痰

## まず覚えること

- 咳＋**息苦しさ、高熱、胸の痛み**なら受診（肺炎など）。
- **3週間以上続く咳**は、結核・喘息・肺がんなどを調べてもらう。
- **血を吐く・血の混じった痰**は受診。量が多ければ119。

## すぐ119

- 大量の血を咳とともに吐く
- 息苦しさが強い、唇が紫
- 突然むせて咳が止まらない（異物の誤嚥）

## 今日中〜数日以内に受診

- 高熱が続く、黄色や緑の痰が増える、息苦しい（肺炎）
- 血の混じった痰
- **3週間以上**続く咳（特に体重減少・寝汗があれば結核も）

## 知っておきたい病気

| 病気 | ひとこと |
|---|---|
| **かぜ** | 数日〜2週間で自然に治る |
| **肺炎** | 発熱、息苦しさ。高齢者は重くなりやすい |
| **咳喘息・喘息** | 夜や明け方の長引く咳 |
| **百日咳** | 大人は長引く咳。乳児は重症になる |
| **結核** | 2週間以上の咳、微熱、体重減少。今も年に約1万人が発症 |
| **肺がん** | たばこを吸う人の長引く咳・血痰 |
