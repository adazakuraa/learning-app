# 胸の痛み

胸痛は、**心臓、血管、肺、食道、骨や筋肉、皮膚、心の状態**など、さまざまな原因で起きます。多くは心配のないものですが、頻度は少なくても**命にかかわる病気**が含まれるため、まず危険な胸痛かどうかを判断します。

## 救急車（119）を考えるサイン

- **胸の中央が締めつけられる、押しつぶされる、重苦しい**痛みが**15〜20分以上**続く（またはおさまらない）
- 痛みが**左肩・腕・あご・首・背中**に広がる
- **冷や汗、吐き気、息苦しさ、顔面蒼白**を伴う
- **突然、胸や背中が裂けるように**痛む（大動脈解離）
- **突然の胸痛と息苦しさ**。とくに長時間座った後、手術・ケガ・長距離移動の後、片足のむくみがある（肺塞栓）。やせ型の若い男性が突然（気胸）。
- 胸痛とともに**失神**した、意識がもうろうとする
- 運動時に起きる胸痛が、**安静にしても治らない**

自分で運転して病院に行かず、**救急車**を使ってください。途中で急変する可能性があるからです。

胸の症状では、**自己判断で薬を飲む必要はありません**。狭心症と診断されてニトログリセリンを処方されている人は、医師から指示された使い方に従います。

## 今日中に受診したいサイン

- **階段や坂道、早足の歩行で胸が締めつけられ、休むと数分で治る**（労作性狭心症。放置すると心筋梗塞に進むことがある）
- 深呼吸や咳で痛みが強くなる、発熱を伴う（胸膜炎、心膜炎、肺炎）
- 動悸、息切れ、むくみがある
- 繰り返し起こる、だんだん増えている

## 女性・高齢者・糖尿病の人の注意

心筋梗塞は、典型的な胸痛が出ないことがあります。**みぞおちの痛み、吐き気、息切れ、だるさ、冷や汗だけ**ということもあります。「胃が痛いだけ」と思わずに、他の危険サインがないか確認してください。

## 様子を見てもよい胸痛の特徴

次のような特徴があれば、心臓以外（筋肉や肋骨、神経）の痛みの可能性が高くなります。ただし、**危険なサインが全くないこと**が前提です。

- 痛い場所を**指で押すと痛む**
- 体を動かす、体をひねる、深呼吸、姿勢で痛みが変わる
- 痛みが**数秒**で消える（針で刺すような痛み）
- 痛む範囲が**指1本で示せる**ほど狭い

## どんな病気が隠れているか

| 病気 | 特徴 |
|---|---|
| **心筋梗塞** | 心臓の血管（冠動脈）が詰まり、心筋が壊れていく。数時間以内の治療（カテーテルで血管を広げる）で予後が大きく変わる |
| **狭心症** | 血管が狭くなり、運動時などに一時的に心筋が酸欠になる。休むと治る |
| **大動脈解離** | 大きな血管の壁が裂ける。突然の激痛、血圧の高い人に多い。緊急手術が必要なことがある |
| **肺塞栓症** | 足の静脈にできた血栓が肺の血管を詰まらせる。エコノミークラス症候群 |
| **気胸** | 肺に穴があいて空気が漏れる。やせ型の若い男性、喫煙者に多い |
| **肺炎・胸膜炎** | 発熱、咳、深呼吸で痛い |
| **逆流性食道炎** | 胸やけ、食後や横になると悪化、酸っぱいものが上がる |
| **帯状疱疹** | 片側の皮膚がピリピリ痛み、数日後に水ぶくれが出る |
| **肋間神経痛・肋軟骨炎** | 押すと痛い、動作で変わる |
| **パニック発作** | 動悸、息苦しさ、胸痛。数分〜30分で治まる（心臓の病気を除いたうえで診断される） |

## 受診のときに

- 痛みの**始まった時刻**、強さ、続いた時間、広がった場所を伝える。
- 持病（高血圧、糖尿病、脂質異常症）、喫煙、家族の心臓病、**飲んでいる薬**を伝える。
- 検査は**心電図、血液検査（心筋の壊れたサイン）、胸部X線**などを行います。最初の検査で正常でも、時間がたってから異常が出ることがあり、**経過観察や繰り返しの検査**をする場合があります。
