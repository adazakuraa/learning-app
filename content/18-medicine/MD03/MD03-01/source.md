# 胸の痛み

## まず覚えること

- **胸がしめつけられる・押される痛みが数分以上**続き、冷や汗や吐き気があれば**すぐ119**（心筋梗塞）。
- **突然の、背中に抜ける引き裂かれるような痛み**は大動脈解離を考えて119。
- 指で押して痛い・体をひねると痛い・数秒で終わるチクッとした痛みは、筋肉や神経のことが多い。

## すぐ119

- 胸の**圧迫感・しめつけ**が数分以上（あご・左腕・背中に広がることも）
- 胸痛＋**冷や汗、吐き気、息苦しさ、失神**
- **突然**の激しい胸や背中の痛み（引き裂かれる、移動する）
- 胸痛＋**急な息苦しさ**（長時間座った後や、片足が腫れている）

**高齢者・糖尿病・女性**は、胸痛がはっきりせず「息苦しい」「だるい」「胃のあたりが変」だけのことがあります。

## 今日中に受診

- 階段や坂道で胸が苦しくなり、休むと治まる（**狭心症**）
- 発熱を伴う胸痛、深呼吸で痛い

## 知っておきたい病気

| 病気 | ひとこと |
|---|---|
| **心筋梗塞** | 心臓の血管が詰まる。1分でも早く治療（カテーテル） |
| **狭心症** | 心臓の血管が狭い。運動で痛み、休むと治まる。心筋梗塞の前段階 |
| **大動脈解離** | 大動脈の壁が裂ける。突然の激痛 |
| **肺塞栓（エコノミークラス症候群）** | 足の血の塊が肺に詰まる。急な息苦しさ |
| **気胸** | 肺に穴があき縮む。やせた若い男性に多い |
| **肋間神経痛・筋肉痛・逆流性食道炎** | 危険は少ないが、自己判断せず一度は受診を |
