# 息苦しさ・呼吸困難

息苦しさは、体が酸素不足に陥りかけているサインかもしれません。**「息苦しい」は、それだけで緊急度が高い症状**として扱います。

## 救急車（119）を考えるサイン

- **話すと息が続かない**（一言ずつしか話せない）
- **横になれない**、座っていないと苦しい（起座呼吸）
- **唇や爪が紫**
- **呼吸がとても速い**（1分間に30回以上）、肩で息をする、のどの下や肋骨の間がへこむ
- **突然**始まった息苦しさ（肺塞栓、気胸、窒息、アナフィラキシー）
- **胸痛、冷や汗、意識がもうろう**
- 蕁麻疹や唇・顔の腫れとともに息苦しい（**アナフィラキシー**）
- **ピンク色の泡状の痰**が出る（心不全による肺水腫）
- 喘息の発作で、**吸入薬を使っても改善しない**、話せない
- 血中酸素飽和度（SpO₂）が**90%以下**

## 今日中に受診したいサイン

- 階段や坂道で、以前より息切れが強くなった
- 咳や痰が増えた、熱がある
- **足のむくみ、体重の急な増加**を伴う（心不全）
- 息苦しさが数日以上続いている
- SpO₂が93%以下

## どんな病気が隠れているか

| 病気 | 特徴 |
|---|---|
| **喘息** | ゼーゼー、ヒューヒュー。夜間・明け方に悪化。アレルギー、風邪、運動がきっかけ。吸入薬で治療 |
| **COPD（慢性閉塞性肺疾患）** | 長年の喫煙。慢性の咳・痰・息切れ。風邪で急に悪化（増悪） |
| **肺炎** | 発熱、咳、痰、息苦しさ。高齢者は熱が出ないことがある |
| **心不全** | 心臓のポンプ機能が落ち、肺に水がたまる。むくみ、体重増、横になると苦しい |
| **気胸** | 突然の胸痛・息苦しさ。やせ型の若い男性、喫煙者 |
| **肺塞栓症** | 突然の息苦しさ、胸痛。足の血栓が原因 |
| **貧血** | 顔色不良、動悸、立ちくらみ |
| **過換気症候群** | 不安やストレスで呼吸が速くなり、手足や口の周りがしびれ、さらに苦しくなる。ゆっくり息を吐く練習で改善。初めての場合は、ほかの病気を調べる必要がある |
| **アナフィラキシー** | 食べ物・薬・蜂などの後、全身の症状（第6章） |

## 受診までにできること

- **楽な姿勢**をとる。座って、少し前かがみ、机にもたれる。
- 窓を開けて換気。衣類をゆるめる。
- **口をすぼめて、ゆっくり吐く**呼吸（口すぼめ呼吸）が楽になることがある。
- 喘息なら**決められた吸入薬を使う**。使っても効かなければ119。
- 食べ物による窒息や異物が疑われる場合は、第12章の対応。
- SpO₂を測れる場合は測る。数字が低ければ受診・救急の判断材料になる。
