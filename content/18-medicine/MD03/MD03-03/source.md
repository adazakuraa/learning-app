# 息苦しさ

## まず覚えること

- **話せないほど苦しい、唇が紫、ゼーゼーがひどい**なら119。
- **横になると苦しく、座ると楽**、足のむくみがあれば心不全を疑う。
- 酸素の値（パルスオキシメーター）が**93%以下**なら急いで受診。

## すぐ119

- 息苦しくて**文が言えない**、肩で息をする
- 唇や顔が紫・青白い、冷や汗、意識がぼんやり
- 急な息苦しさ＋**胸の痛み**
- 食べ物の後・虫刺されの後の息苦しさ・顔の腫れ（**アナフィラキシー**、第6章）
- 喉に物が詰まった（**窒息**、第12章）

## 今日中に受診

- 発熱＋息苦しさ（肺炎）
- 喘息の発作で、いつもの吸入が効かない
- 夜、横になると苦しくて目が覚める（心不全）

## 知っておきたい病気

| 病気 | ひとこと |
|---|---|
| **喘息** | 気道が狭くなる。ゼーゼー、夜や明け方に悪化 |
| **COPD** | 主にたばこが原因。少しの動作で息切れ |
| **肺炎** | 発熱、咳、息苦しさ。高齢者は熱が出ないことも |
| **心不全** | 心臓のポンプが弱る。むくみ、横になると苦しい |
| **過換気** | 不安などで呼吸が速くなる。手足のしびれ。体の病気を否定してから |
