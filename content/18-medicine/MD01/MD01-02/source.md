# 緊急度の考え方：バイタルサインと「いつもと違う」

緊急度は、症状の名前ではなく、**体の状態そのもの**で決まります。その状態を数字や観察で表したのが**バイタルサイン**（生命徴候）です。

## まず見る5つ

| 項目 | 見方 | 危険の目安 |
|---|---|---|
| **意識** | 名前を呼ぶ、肩をたたいて反応を見る | 反応が鈍い、目を開けない、つじつまの合わない返事 → **119** |
| **呼吸** | 回数（1分間）、苦しそうか、ゼーゼー音、唇の色 | 話すと息が続かない、安静でも苦しい、唇が紫、肩で息をする → **119** |
| **脈拍** | 手首で1分数える（成人の通常は60〜100） | 安静で120以上が続く、50未満でふらつく、不規則で息苦しい → 受診、症状が強ければ**119** |
| **血圧** | 家庭用血圧計 | 上（収縮期）が90未満で冷や汗・ふらつき → **119**。180以上で頭痛・胸痛・麻痺・息切れ → 救急 |
| **体温** | 体温計（わきの下） | 37.5℃以上が発熱。数字より**ぐったり度**を重視 |

もう一つ、**血中酸素飽和度（SpO₂）**は、指先に挟む「パルスオキシメーター」で測ります。健康な人は95%以上です。**93%以下**なら当日の受診相談、**90%以下**なら救急要請を考える目安です（寒い手や爪の汚れで低く出ることがあります）。

## 数字が測れなくても見られるサイン

- **顔色**：蒼白、土気色、唇や爪が紫（チアノーゼ）
- **冷や汗**：暑くないのに全身に汗をかいている
- **皮膚**：冷たく湿っている。まだらな模様が出ている
- **意識**：ぼんやり、受け答えが遅い、普段と違う言動

## 急に始まったか、ゆっくりか

**数秒〜数分で始まり、最初から最大に強い症状**は、血管が詰まる、破れる、裂ける、臓器がねじれる、といった「突然のできごと」が体の中で起きた可能性があります。

- 「**突然**、バットで殴られたような頭痛」
- 「**突然**、胸を締めつけられる痛み」「突然、背中が裂けるような痛み」
- 「**突然**、片方の手足が動かない」

こうした症状は、数日かけてじわじわ悪くなる症状よりも、緊急度が高い傾向があります。

## 本人の背景で基準が変わる

前の単元で書いたように、高齢者、乳児、妊娠中、持病のある人、免疫を抑える薬や血液をサラサラにする薬を使っている人は、**基準を一段厳しく**します。

## 緊急度の4段階

| 段階 | 行動 | 例 |
|---|---|---|
| ① 今すぐ | **119** | 意識がない、呼吸が苦しい、突然の激しい症状、大量出血 |
| ② 今日中 | 夜間・休日でも受診（#7119で相談） | 高熱でぐったり、強い腹痛、我慢できない痛み |
| ③ 数日以内 | 予約して受診 | 長引く咳、徐々に悪化する症状、体重が減る |
| ④ 様子見 | 自宅で休む（悪化の条件を決める） | 軽いかぜ、軽い筋肉痛 |

## 全身に共通する「危険なサイン」一覧

次のどれか1つでも当てはまれば、まず**119（または#7119）**を考えてください。

- 呼びかけに反応が悪い、意識がもうろうとしている
- 息が苦しくて話せない、唇が紫
- 胸の強い痛み、締めつけ、冷や汗
- 突然の激しい頭痛、突然の麻痺・しびれ・ろれつの乱れ・視野の異常
- けいれんが5分以上続く、けいれんが止まっても意識が戻らない
- 止まらない大量の出血、血を吐く、真っ黒な便が出る
- 強い腹痛でお腹が硬い・動けない
- 蕁麻疹とともに息苦しさ、顔や唇の腫れ、ぐったり（アナフィラキシー）
- 高熱とともに強い頭痛・首が硬い・意識が悪い・点状の出血斑
- 生後3か月未満の発熱、ぐったりして反応が弱い子ども
- 妊娠中の大量出血・破水・強い腹痛
- 自分を傷つけた、あるいはその危険が差し迫っている

---

*ここに書いてあるのは一般的な目安で、診断ではありません。迷うとき、いつもと違うと感じるとき、悪くなっていくときは、受診や相談（#7119・119）をためらわないでください。*
