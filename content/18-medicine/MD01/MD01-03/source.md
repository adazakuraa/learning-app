# どこに相談する？119・#7119・診療科

## まず覚えること

- 迷ったら**#7119**（救急相談）。子どもは**#8000**。
- 命にかかわりそうなら迷わず**119**。救急車を呼んで軽症でも責められない。
- 診療科がわからなければ**内科**か、**病院に電話で聞く**。

## 電話の使い分け

| 番号 | 使うとき |
|---|---|
| **119** | 命にかかわりそうなとき |
| **#7119** | 救急車を呼ぶか、今すぐ受診すべきか迷うとき（実施していない地域もある） |
| **#8000** | 子どもの症状で迷うとき（夜間・休日） |
| **中毒110番** | 何かを飲み込んだとき（大阪 072-727-2499、24時間） |

総務省消防庁のアプリ「**Q助**」でも緊急度を調べられます。

## 迷ったときの診療科

| 症状 | 科 |
|---|---|
| よくわからない・全身の症状 | 内科 |
| けが・骨・腰 | 整形外科 |
| 皮膚 | 皮膚科 |
| 目・耳鼻のど | 眼科・耳鼻咽喉科 |
| 子ども | 小児科 |
| 心の不調 | 心療内科・精神科 |

夜間・休日は、地域の**休日夜間急患センター**や救急病院へ。
