# どこに連絡する？救急車・相談窓口・診療科

## 119（救急車）

**命にかかわるおそれがある、またはその可能性を否定できないとき**に使います。料金は無料です。携帯電話からもかけられます。

呼ぶべきか迷うときは、**呼んでかまいません**。ただし、あまりに軽い症状での利用が増えると、本当に必要な人に救急車が届かなくなります。迷うときは、次の相談窓口を使うとよいでしょう。

自分で運転して行ってはいけない症状もあります。**胸痛、意識がもうろうとする、麻痺、強いめまい、けいれん後**は、途中で急変する可能性があるため、救急車を使ってください。

## #7119（救急安心センター）

「救急車を呼ぶべきか」「今すぐ病院に行くべきか」を、**看護師や医師が電話で相談に乗ってくれる**窓口です。緊急性が高ければ、そのまま救急車を手配してくれます。

- 多くの地域で24時間（地域によって時間が違う）
- 全国に広がっていますが、**まだ使えない地域もあります**。使えない地域では、自治体の相談窓口や#8000を案内するサイトがあります。お住まいの自治体の案内を一度確認しておきましょう。

## #8000（子ども医療電話相談）

**15歳未満（地域により異なる）の子ども**の急な症状について、小児科医や看護師に相談できます。多くは**夜間・休日**に開設されています。時間帯は都道府県で違います。

## 医療機関の階層

| 区分 | 役割 | 例 |
|---|---|---|
| 初期（一次）救急 | 軽症〜中等症。入院が不要な人 | 休日夜間急患センター、在宅当番医、かかりつけ医 |
| 二次救急 | 入院が必要な人 | 地域の救急病院 |
| 三次救急 | 命にかかわる重症の人 | 救命救急センター |

救急車で運ばれる先は、救急隊が症状と受け入れ状況で決めます。

**救急外来は、重症の人から順に診ます**。軽症だと長く待つことがあります（これを**トリアージ**といいます）。紹介状なしで大きな病院を受診すると、初診に**追加料金（選定療養費）**がかかる場合があります。

## 診療科の選び方

| 症状 | 診療科 |
|---|---|
| 発熱、かぜ、腹痛、だるい、よく分からない | **内科**（総合診療科）、かかりつけ医 |
| 胸痛、動悸、息切れ | 循環器内科（救急は119） |
| 頭痛、しびれ、めまい | 脳神経内科、脳神経外科（緊急は119） |
| 胃・腸・肝臓 | 消化器内科 |
| 咳、ぜんそく | 呼吸器内科 |
| 骨・関節・腰・ケガ | 整形外科 |
| 皮膚の発疹、かゆみ | 皮膚科 |
| 目 / 耳・鼻・のど | 眼科 / 耳鼻咽喉科 |
| 尿・男性の性器 | 泌尿器科 |
| 女性の下腹部・月経・妊娠 | 産婦人科（婦人科） |
| 気分の落ちこみ、不眠、不安 | 精神科、心療内科 |
| 子ども | 小児科 |

迷ったら**内科**か、かかりつけ医に電話してください。適切な診療科を案内してくれます。

## 医療機関を探す

- 各都道府県の**医療情報ネット（ナビイ）**：診療科、時間、対応可能な検査などを検索できる。
- 夜間・休日は、自治体の案内（休日夜間急患センター、当番医）を確認する。
- **オンライン診療・電話相談**は、休日夜間の相談や軽症の確認には便利ですが、**診察できることは限られます**。胸痛・意識障害・強い腹痛などの重い症状には向きません。

## 普段から準備しておくこと

- **かかりつけ医**を決めておく（持病の経過を知っている医師）
- **お薬手帳**（アプリでも可）、保険証（マイナ保険証）を持ち出せる場所に置く
- 自治体の**休日夜間急患センター**の場所と、#7119・#8000が使えるか確認しておく

---

*ここに書いてあるのは一般的な目安で、診断ではありません。迷うとき、いつもと違うと感じるとき、悪くなっていくときは、受診や相談（#7119・119）をためらわないでください。*
