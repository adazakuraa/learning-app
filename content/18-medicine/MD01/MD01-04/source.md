# 症状の伝え方と119番通報

医師や救急隊は、**短い時間で必要な情報を聞き出す**必要があります。あらかじめ整理しておくと、診断も搬送先選びも速くなります。

## 伝える項目（受診でも通報でも共通）

1. **いつから**：何時何分、何日前から。急に始まったか、じわじわか。
   - 脳卒中が疑われるときは**「最後に普段どおりだった時刻」**が特に重要です（治療の可否を決めます）。
2. **どんな症状か**：場所、痛みの種類（ズキズキ、締めつけ、差し込む）、強さ（0〜10で何点か）、続いているか、波があるか。
3. **どう変わってきたか**：悪化、改善、変わらない。
4. **ほかの症状**：熱、吐き気、息苦しさ、冷や汗、しびれ、発疹、下痢、血尿など。
5. **持病・手術歴**：高血圧、糖尿病、心臓病、腎臓病、ぜんそく、がん、妊娠の可能性。
6. **飲んでいる薬**：特に**血をサラサラにする薬**、糖尿病薬、ステロイド。お薬手帳があれば見せる。
7. **アレルギー**：薬、食べ物、造影剤。
8. **きっかけ**：食べたもの、ケガ、運動、旅行、周りに同じ症状の人、ダニや虫、ペットなど。

写真が役に立つ場合もあります（発疹、腫れ、便や嘔吐物の色）。

痛みの伝え方は、医療現場では次の6点（**OPQRST**）で整理することがあります。

| | 意味 | 例 |
|---|---|---|
| O（Onset） | いつ・どう始まったか | 2時間前に突然 |
| P（Provocation） | 何で悪化・軽減するか | 動くと痛い、横になると楽 |
| Q（Quality） | どんな痛みか | 締めつける、刺す |
| R（Region/Radiation） | どこが痛い、どこに広がるか | 胸から左腕・あごへ |
| S（Severity） | 強さ | 10段階で8 |
| T（Time） | 続く時間・経過 | 15分続いて、まだ続く |

## 119番通報の流れ

1. **「救急です」**と伝える（火事ではないことを最初に言う）。
2. **場所**：住所、建物名、目印。携帯では位置が違うことがあるので、住所を必ず伝える。
3. **何があったか**：「父が胸を押さえて倒れた」「子どもがけいれんしている」。
4. **年齢と性別**。
5. **意識があるか、息をしているか**。
6. **持病・飲んでいる薬**（分かる範囲で）。
7. **名前と連絡先**（折り返しがあることがある）。

**電話は、こちらから切らない**でください。通報を受けた人が、その場でできる手当（心臓マッサージなど）を指示してくれることがあります。

## 通報後、救急隊が来るまでに

- **玄関や門を開け**、救急車を誘導する人を道に出す。
- **保険証（マイナ保険証）、お薬手帳、現金、靴、携帯電話**を用意する。
- 患者の様子を見守り、変化（意識、呼吸、けいれん）をメモする。
- 吐いたときのために、**横向き（回復体位）**にしておく。
- 吐いたもの、飲んだ薬のシート、ケガの原因になったものがあれば持っていく。
- 飲食は控える（手術や検査に影響するため）。

## 付き添い・費用

- 付き添いは可能なことが多く、状況を説明できる人が同乗してください。
- **救急車の利用料金は、現在、ほとんどの地域で無料**です。ただし、**軽症での救急搬送に追加料金をとる**取り組みを始めた自治体もあります。お住まいの地域の最新の情報を確認してください。
- 搬送先は、救急隊が症状と受け入れ状況で選びます。かかりつけ病院を希望できる場合もありますが、受け入れられないこともあります。
