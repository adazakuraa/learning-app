# 口・歯・あごの症状

## 歯の痛み

### 緊急性のサイン（歯科・口腔外科、救急）

- **顔や首が腫れて、飲み込みにくい、口が開かない、息苦しい**：歯の感染が深部に広がっている（**蜂窩織炎、深頸部感染症**）。**救急**。
- **発熱を伴う強い痛み、歯ぐきの腫れ**
- **歯が折れた・抜けた**：**歯を抜けたまま乾燥させない**。**牛乳、または口の中（頬と歯ぐきの間）**に入れて、**30分以内**に歯科へ行くと、再び植えられる可能性が高い。**根を触らない**。**水道水で洗いすぎない**。
- **顎が外れた**（口が閉じられない）：動かさず、歯科・口腔外科へ。

### 歯の痛みの原因

- **むし歯（う蝕）**：進行すると**冷たい物や熱い物がしみる → 何もしなくてもズキズキ痛む（歯髄炎）→ 根の先に膿**。**痛みがなくなったときは治ったのではなく、神経が死んだ**可能性。
- **歯周病**：歯ぐきの腫れ、出血、歯がぐらぐら。**日本人の歯を失う最大の原因**。**糖尿病、心臓病、誤嚥性肺炎、早産**との関連が知られている。
- **親知らず**の炎症（智歯周囲炎）：腫れ、痛み、口が開きにくい。
- **歯ぎしり、食いしばり**：朝の顎のだるさ、歯のすり減り。

### 痛み止め

- 歯の痛みには、**アセトアミノフェンやNSAIDs**（第1章）が使える。ただし**歯科に行くまでのつなぎ**にすぎない。

## 顎の症状

- **顎関節症**：口を開けると**カクカク音がする、痛む、開きにくい**。多くは自然に、または自己管理（硬い物を避ける、食いしばりを意識する）で軽快する。
- **顎が痛く、運動や階段で悪化する**：**狭心症**の関連痛（第3章）の可能性。

## 口の中

| 症状 | 考えられるもの | 目安 |
|---|---|---|
| **口内炎**（白い、痛い） | アフタ性口内炎 | **2週間以上治らない**、繰り返す → 受診 |
| **治らない口内炎、しこり、白や赤の斑** | **口腔がん**、前がん病変 | **2週間以上**治らなければ、歯科口腔外科・耳鼻科へ。喫煙・飲酒でリスクが上がる |
| 白いカス状の苔 | **口腔カンジダ症** | ステロイド吸入薬、抗菌薬、免疫低下で |
| 口が乾く | **ドライマウス**、薬の副作用、シェーグレン症候群、糖尿病 | 原因を探る |
| 口臭 | 口の中の問題（歯周病、舌苔）が大部分 | 歯科で。胃や、まれに全身の病気 |
| 唇や口の水ぶくれ | **口唇ヘルペス** | 再発することが多い。抗ウイルス薬 |

## 歯科受診の習慣

- **定期的な歯科検診（半年〜1年に1回）**で、歯石の除去、むし歯・歯周病の早期発見ができる。
- **フッ素入り歯みがき剤**、歯間ブラシ・フロスが有効。
- **高齢者の口腔ケア**は、**誤嚥性肺炎を減らす**（第10章）。
