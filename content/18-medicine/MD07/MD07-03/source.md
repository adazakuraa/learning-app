# 鼻の症状：鼻血・鼻づまり・においがおかしい

## 鼻血

ほとんどは**鼻の入り口の近く（キーゼルバッハ部位）**からの出血で、**正しく止めれば10〜15分以内**に止まります。

### 止め方

1. **座って、少し前かがみ**になる（**上を向かない**、寝ない：血がのどに流れて吐き気の原因になる）。
2. **鼻の柔らかい部分（小鼻）を、親指と人差し指で強くつまむ**。
3. **10分間**、つまみ続ける（途中で離して確認しない）。
4. 口に流れてきた血は**飲み込まず、吐き出す**。冷やすのも補助になる。

### 受診・119の目安

- **15〜20分圧迫しても止まらない**
- **勢いよく大量に出る**、ふらつき、顔色が悪い
- **頭や顔を強く打った後**の鼻血、透明な液が混じる
- **血をサラサラにする薬**（抗凝固薬、抗血小板薬）を飲んでいる
- **繰り返す**（腫瘍、血が止まりにくい病気、高血圧）
- 子どもで頻回、**あざもできやすい**

## 鼻づまり・鼻水

| 原因 | 特徴 |
|---|---|
| **かぜ** | 数日〜1週間 |
| **アレルギー性鼻炎・花粉症** | 水っぽい鼻水、くしゃみ、目のかゆみ。季節性 |
| **副鼻腔炎（蓄膿症）** | 黄色〜緑の粘り気のある鼻水、**顔（頬、額、目の奥）の痛みや重さ**、悪臭、**10日以上続く**、いったん良くなって再び悪化 |
| **鼻茸、鼻中隔弯曲** | 慢性的な鼻づまり |
| **薬剤性鼻炎** | 点鼻薬（血管収縮薬）の使いすぎ。長期連用しない |

### 急ぐべき副鼻腔炎

- **目の周りの赤み・腫れ、視力の変化、強い頭痛、高熱、首の硬さ**：感染が目や脳に広がっている可能性。**緊急**。

## 子どもの鼻

- **片方の鼻だけ**、悪臭のある鼻水：**異物**を疑う。
- 豆やおもちゃなどは、取れないときは耳鼻科へ（第6章）。

## においがおかしい

- **においがしない（嗅覚障害）**：かぜ、**新型コロナ**、副鼻腔炎、アレルギーなど。
- **においがしないことに気づきにくい**ため、**ガス漏れや食品の腐敗**に気をつける。
- **数週間以上**続く、においがしない以外にも神経症状（物忘れ、ふるえ）がある場合は受診。**嗅覚の低下は、パーキンソン病やアルツハイマー病の早期サイン**のことがある。
- **存在しないにおい**（幻臭）が突然する、意識がもうろうとする：てんかんの前ぶれのこともある。
