# 頭痛

頭痛の大半は、片頭痛や緊張型頭痛など、命にかかわらないものです。しかし、ごく一部に**くも膜下出血や髄膜炎**のような、数時間〜数日で命にかかわる病気が隠れています。まず危険なサインを確認します。

## 救急車（119）を考えるサイン

- **突然始まった、これまで経験したことのない激しい頭痛**（「バットで殴られたような」「人生最悪の頭痛」）。数秒〜1分でピークに達する。
- 頭痛に加えて**意識がもうろうとする、けいれんする**
- **手足の麻痺、しびれ、ろれつが回らない、顔のゆがみ、物が二重に見える、視野が欠ける**（脳卒中のサイン）
- **高熱と首の硬さ**（あごを胸につけられない）、発疹、光がまぶしい（髄膜炎のサイン）
- 頭を打った後に悪化する頭痛、繰り返す嘔吐
- **片目の激しい痛みに、吐き気・視力低下・目の充血**（急性緑内障）
- 妊娠後期〜産後の頭痛に、血圧上昇・むくみ・目のチカチカ（子癇前症）
- **家族みんなが頭痛と吐き気**：暖房や給湯器の不完全燃焼による**一酸化炭素中毒**の可能性。窓を開けて屋外に出て、119。

## 今日中に受診したいサイン

- **50歳以降に初めて起きた**頭痛、これまでと違うタイプの頭痛
- 数日〜数週間かけて**徐々に悪化**している（高齢者や頭を打った後なら**慢性硬膜下血腫**の可能性）
- **朝に強く、吐き気を伴い、咳やいきみで悪化**する
- **こめかみ**が痛み、噛むとあごが疲れる、頭皮を触ると痛い（50歳以上は側頭動脈炎で、放置すると失明することがある）
- 発熱を伴う頭痛
- 血液をサラサラにする薬（抗凝固薬）を飲んでいる人の頭痛

## 様子を見てよい目安

- 以前から何度も経験している**いつもの頭痛**で、強さも出方も変わらない
- 神経のサイン（麻痺、ろれつ、視野）がなく、意識もはっきりしている
- 休息や市販の鎮痛薬で和らぐ

ただし、**市販の鎮痛薬を月に10〜15日以上**飲む状態は、薬そのものが頭痛を引き起こす「薬剤使用過多頭痛」の可能性があります。受診して相談してください。

## どんな病気が隠れているか

| 病気 | 特徴 |
|---|---|
| **緊張型頭痛** | 最も多い。頭全体や後頭部を「締めつける」ような鈍い痛み。肩こり、ストレス、同じ姿勢で悪化。吐き気は少ない |
| **片頭痛** | 片側または両側の**ズキズキ**する痛み、4〜72時間続く。吐き気、光や音がつらい。動くと悪化。若い女性に多い。前兆（ギザギザの光）を伴うことも。専用の薬（トリプタン）がある |
| **群発頭痛** | 目の奥をえぐるような**激痛**が片側に。夜中や同じ時刻に起き、1〜2か月集中して繰り返す。涙や鼻水を伴う。男性に多い |
| **くも膜下出血** | 脳の血管のこぶ（動脈瘤）が破れる。突然の激しい頭痛。緊急手術の対象 |
| **脳出血・脳梗塞** | 麻痺やろれつ障害を伴うことが多い |
| **髄膜炎** | 発熱、首の硬さ、頭痛。ウイルス性と細菌性があり、細菌性は急速に悪化する |
| **慢性硬膜下血腫** | 軽く頭を打った数週間後に、頭痛、物忘れ、歩きにくさ。高齢者や飲酒する人に多い。手術で治る |
| **副鼻腔炎** | 顔や額の痛み、鼻づまり、膿の鼻水。かぶる、下を向くと痛む |
| **薬剤使用過多頭痛** | 鎮痛薬の飲みすぎで頭痛が慢性化する |

## 受診までにできること

- 暗く静かな場所で休む。冷やすと楽になることが多い（片頭痛）。
- 水分をとる。食事を抜かない。
- 鎮痛薬は、**アセトアミノフェン**が胃腸や血圧への影響が少なく使いやすい。普段飲んでいる薬があればそれを。
- 頭痛の記録（いつ、何時間、強さ、きっかけ）をつけておくと診断に役立つ。
