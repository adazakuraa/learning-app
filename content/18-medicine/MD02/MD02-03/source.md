# 脳卒中：手足のしびれ・麻痺・ろれつ

**脳卒中**は、脳の血管が詰まる、または破れる病気の総称です。日本人の死因や、寝たきりの原因の上位にあたります。治療の効果は**発症からの時間**で大きく変わるため、「迷わず救急車」が原則です。

## FASTで見分ける

| | 見るところ | 異常 |
|---|---|---|
| **F**ace（顔） | 笑ってもらう | 片側の口角が下がる、顔がゆがむ |
| **A**rm（腕） | 両腕を前に上げて目を閉じる | 片方が下がる、上がらない |
| **S**peech（言葉） | 短い文を言ってもらう | ろれつが回らない、言葉が出ない、理解できない |
| **T**ime（時間） | | **1つでもあれば、すぐ119。発症時刻をメモ** |

加えて、**ふらついて歩けない（Balance）**、**物が二重に見える・視野が欠ける（Eyes）**も脳卒中のサインです（BE-FAST）。

## 救急車（119）を考えるサイン

- 上のサインが**1つでもある**。軽い、あるいは数分で消えた場合も同じです。
- **突然の激しい頭痛**、意識がもうろうとする。
- 「最後に普段どおりだった時刻」をはっきり伝える。**朝起きたら麻痺があった場合は、寝る前の時刻**が基準になります。

## 一時的に消えるサインも「救急」

症状が数分〜1時間で完全に消えるものを**一過性脳虚血発作（TIA）**といいます。「治まったから様子見」にしてはいけません。TIAの後は、**48時間以内に脳梗塞を起こす危険が高い**ことが知られています。症状が消えても、**当日中に受診**（できれば救急）してください。

## どんな病気か

- **脳梗塞**（約7割）：血管が詰まる。動脈硬化で詰まる、**心房細動**で心臓にできた血の塊が飛んで詰まる、細い血管が詰まる、のタイプがある。
- **脳出血**：高血圧で細い血管が破れる。
- **くも膜下出血**：血管のこぶが破れる。突然の激しい頭痛。

脳梗塞の治療には、血栓を溶かす薬（**t-PA**、発症から4.5時間以内が目安）と、カテーテルで血栓を取り除く治療（血栓回収、条件が合えばさらに長い時間でも可能）があります。治療できるかどうかは、**救急車で搬送し、画像検査をして初めて決まる**ので、自分で判断して様子を見ないことが大切です。

## しびれの原因は脳卒中だけではない

しびれのうち、**片側の手足に突然**出るものは脳卒中を疑います。ほかの原因もあります。

- **手根管症候群**：夜間や朝に、親指〜薬指がしびれる。手を振ると楽になる。
- **頸椎症・椎間板ヘルニア**：首や腰から腕・脚に走るしびれ。姿勢で変わる。
- **糖尿病性神経障害**：両足の先が左右対称にじんじんしびれる。
- **ビタミンB12不足**、アルコール
- **過換気**：両手足と口の周りがしびれ、息が速い。
- **ギラン・バレー症候群**：感染の後、数日で足から力が入らなくなり、上へ広がる（受診が必要）。
- **脊髄の病気**：両足の麻痺、**排尿・排便ができない、股の感覚がない**（馬尾症候群）は緊急。

## 受診・通報時にできること

- 横にして楽な姿勢にする。吐きそうなら**横向き**。
- **飲食、薬を口に入れない**（飲み込めずにむせる）。
- 発症時刻、飲んでいる薬（とくに血液をサラサラにする薬）、持病を伝える。
- 血圧を無理に下げる必要はなく、自己判断で薬を飲み足さない。

## 予防

脳卒中の最大の危険因子は**高血圧**です。ほかに糖尿病、脂質異常症、**心房細動**、喫煙、飲酒。健診の血圧や心電図を放置しないことが予防になります（第13章）。
