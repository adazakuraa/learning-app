# 脳卒中

## まず覚えること

- **顔のゆがみ・片腕が上がらない・ろれつ**のどれか1つでも出たら**すぐ119**。
- **発症した時刻**（最後に普段どおりだった時刻）を必ず伝える。
- 症状が数分で消えても**受診が必要**（脳梗塞の前ぶれ）。

## 脳卒中を疑う「FAST」

| | 見るところ |
|---|---|
| **F**ace（顔） | 「イー」と笑うと片側が下がる |
| **A**rm（腕） | 両腕を前に上げると片方が下がる |
| **S**peech（言葉） | ろれつが回らない、言葉が出ない |
| **T**ime（時間） | すぐ119、発症時刻を確認 |

ほかに、**急に片目が見えない・ものが二重**、**急にまっすぐ歩けない**も脳卒中のサインです。

## なぜ急ぐのか

脳梗塞は、発症から**数時間以内**なら、血の塊を溶かす薬やカテーテルで詰まりを取る治療ができ、後遺症を減らせます。時間がたつほど脳が死んでいきます。

## 脳卒中の種類

| 種類 | ひとこと |
|---|---|
| **脳梗塞** | 脳の血管が詰まる。最も多い |
| **脳出血** | 脳の中の血管が破れる。高血圧が大きな原因 |
| **くも膜下出血** | 脳の表面の血管のこぶが破れる。突然の激しい頭痛 |
| **一過性脳虚血発作（TIA）** | 症状が数分〜24時間以内に消える。脳梗塞の前ぶれ |

## 予防

**高血圧の治療**、禁煙、糖尿病・脂質異常症の管理、**心房細動**（不整脈）の治療。
