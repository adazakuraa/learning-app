# 排尿の症状：血尿・頻尿・尿が出ない

## 救急・今日中の受診を考えるサイン

- **尿がまったく出ない**、下腹部がパンパンに張って痛い（**尿閉**）。男性の前立腺肥大、薬の影響、脊髄の病気など。
- **発熱（悪寒）＋背中・脇腹の痛み**：**腎盂腎炎**。**血圧が下がる、ぐったり**していれば敗血症（第5章、**119**）。
- **側腹部から背中・下腹部へ波のある激痛、冷や汗、吐き気**：**尿管結石**。
- **陰嚢（睾丸）の突然の激痛**（特に思春期の男子）：**精巣捻転**。**6時間以内に手術**しないと精巣を失う。**痛みで夜中に目が覚めた、吐き気**。恥ずかしがらず**救急**。
- **血尿**（赤い、茶色いコーラ色）：痛みがなくても、**必ず受診**（膀胱がん・腎臓がんのサインのことがある）。
- **血の塊で尿が出ない**

## 主な病気

| 病気 | 特徴 |
|---|---|
| **膀胱炎** | **女性に多い**。頻尿、排尿時痛、**残尿感**、尿が濁る。**発熱は通常ない**。抗菌薬で治る。水分を十分にとる |
| **腎盂腎炎** | 膀胱炎が腎臓まで上がる。**発熱、背中の痛み**。入院が必要なことも |
| **尿管結石** | 脇腹の激痛、血尿。**自然に出る**ことが多いが、痛みが強い、発熱があれば受診 |
| **前立腺肥大症** | **中高年男性**。尿の勢いが弱い、夜間頻尿、残尿 |
| **前立腺がん** | 早期は無症状。**PSA検査**（第13章） |
| **過活動膀胱** | 急に尿意が強い、漏れる |
| **尿失禁** | 咳やくしゃみで漏れる（腹圧性、女性に多い）、薬・生活で改善する |

## 尿の色

- **濃い黄色**：脱水
- **赤・茶色**：血尿、ミオグロビン尿（筋肉の損傷）、食べ物（ビーツ）、薬
- **濁り・泡立ち**：感染、タンパク尿（腎臓病）
- **ビタミン剤やビタミンB**で明るい黄色になることがある。

## 男性の性器の症状

- **尿道からの膿、排尿時痛**：**淋菌・クラミジア感染**（第5章）。パートナーと一緒に治療する。
- **包茎・嵌頓包茎**：反転した包皮が戻らず、亀頭が腫れて痛い（緊急）。
- **ペニスの強い痛みを伴う勃起が4時間以上**（持続勃起症）：**緊急**。

## 自宅でできること（膀胱炎）

- 水分をとる、**排尿を我慢しない**。
- 症状が出たら**早めに受診**（市販薬のみで済ませず、**2日以上、あるいは悪化**ならば特に）。
- **妊婦、男性、子ども、繰り返す膀胱炎**は、必ず受診。
