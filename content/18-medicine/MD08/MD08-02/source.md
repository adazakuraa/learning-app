# 女性の症状：月経・不正出血・下腹部痛

## 救急・今日中の受診を考えるサイン

- **妊娠の可能性がある（または検査で陽性）＋下腹部痛や出血**：**子宮外妊娠**（卵管などに着床）。**破裂すると大量出血、ショック**に至る。**肩の痛み**、ふらつき、冷や汗。**119**。
- **突然の激しい下腹部痛**、吐き気（**卵巣嚢腫の茎捻転、卵巣出血**）
- **発熱を伴う下腹部痛、おりもの**（**骨盤内炎症性疾患**）
- **月経のとき、1〜2時間おきにナプキンを替えるほどの出血**、ふらつき、動悸（貧血）
- **閉経後の出血**：必ず婦人科を受診（子宮体がんなどのサイン）。
- **トイレで血のかたまり、立ちくらみ**

## 月経の基本

- **周期は25〜38日**、**期間は3〜7日**が正常の範囲。
- 規則的でも、不規則でも、**急に変わった**場合は相談。
- **3か月以上月経がない（妊娠以外）**：無月経。婦人科へ。
- **月経前の不調（PMS）**：イライラ、むくみ、乳房痛。**強い抑うつ、日常生活に支障（PMDD）**があれば治療がある。

## 月経痛と婦人科の病気

| 病気 | 特徴 | 目安 |
|---|---|---|
| **月経困難症** | 月経のときの強い痛み、仕事や学校を休む | 市販の鎮痛薬で足りなければ婦人科へ。**低用量ピル**などの治療がある |
| **子宮内膜症** | 月経痛が**年々強くなる**、性交痛、不妊 | 放置せず婦人科へ。**チョコレート嚢胞** |
| **子宮筋腫** | 過多月経、貧血、下腹部のしこり | 良性。症状や大きさで治療 |
| **子宮頸がん** | 初期は**無症状**。性交後の出血、おりものの異常 | **HPVワクチン、20歳からの検診**（第13章） |
| **子宮体がん** | **閉経後・不規則な出血** | すぐ受診 |
| **卵巣がん** | 症状が出にくい。腹部の張り | |
| **多嚢胞性卵巣症候群（PCOS）** | 月経不順、ニキビ、多毛 | 治療あり |

## おりもの・外陰部のかゆみ

- **白いカッテージチーズ状、強いかゆみ**：**カンジダ**。
- **灰色〜黄色、魚くさい**：**細菌性腟症**、**トリコモナス**。
- **膿のようなおりもの、下腹部痛**：**クラミジア、淋菌**。
- 市販薬の使用は、**過去に同じ診断を受けた場合**に限る。そうでなければ婦人科。

## 乳房の症状

- **しこりに気づいた、乳頭から血の混じった分泌、皮膚のくぼみ**：**乳腺外科**へ。痛みだけのことは、月経前のホルモンの影響が多い。
- **乳がんは日本の女性で最も多いがん**。**40歳からのマンモグラフィ検診**（第13章）。**セルフチェックだけでは死亡率を下げるとは示されていない**が、しこりに気づいたら受診する。

## 妊娠の可能性があるとき

- **妊娠の可能性がある場合は、薬、レントゲン検査を受ける前に伝える**。
- 月経が遅れたら、**妊娠検査薬**（月経予定日の1週間後から）。陽性なら産婦人科を受診。
