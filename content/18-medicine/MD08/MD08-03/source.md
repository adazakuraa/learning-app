# 妊娠中・産後の症状

妊娠中は、**自分と赤ちゃんの2人分**を考えます。迷ったら、**かかりつけの産婦人科、または母子手帳に書かれた連絡先**に電話します。夜間・休日の連絡先を確認しておきましょう。

## すぐ連絡・救急を考えるサイン

- **腟からの出血**（少量でも、妊娠中は連絡）
- **破水**（水のような液体が流れる、止まらない）：**ナプキンを当てて**、横になり、すぐに連絡。**救急車を呼んでよい**。
- **規則的なお腹の張りや痛み**（**妊娠37週未満**は早産のおそれ）
- **赤ちゃんの動きが、いつもより明らかに少ない、感じない**
- **強い頭痛、目がチカチカする、視界がおかしい、上腹部の痛み、顔や手の強いむくみ、急な体重増加**（**妊娠高血圧症候群・子癇**。けいれんする可能性）
- **けいれん、意識障害**
- **強い腹痛**（常位胎盤早期剥離：突然の持続する腹痛、出血）
- **発熱、強い嘔吐で水分がとれない**

## 妊娠中によくある症状

| 症状 | 目安 |
|---|---|
| **つわり** | 吐き気は妊娠初期（5〜16週頃）に多い。**水分も食事もとれず、体重が減る、尿が出ない**（**妊娠悪阻**）なら受診、点滴 |
| **腰痛、足のむくみ、こむら返り** | 通常の範囲が多い。**片足だけ腫れて痛い**は静脈血栓症で、肺塞栓に至ることがある。**息苦しさ、胸痛**を伴えば救急 |
| **お腹の軽い張り** | 休むと治まるなら様子見 |
| **便秘、痔、頻尿** | 生活の工夫、相談 |
| **貧血** | 鉄剤で治療 |

## 妊娠中の薬と感染症

- 市販薬を飲む前に、**必ず医師か薬剤師**に妊娠中であることを伝える。**NSAIDs（ロキソプロフェン、イブプロフェン）は妊娠後期に避ける**。**アセトアミノフェン**は比較的使いやすい（それでも相談）。
- **インフルエンザ・新型コロナの予防接種**は勧められることがある（相談）。
- **風疹・麻疹・水痘**は、胎児に影響する。**妊娠前**に、免疫があるか確認し、ワクチンを受けておく（妊娠中は生ワクチンを受けられない）。
- **生肉、加熱不足の肉、ナチュラルチーズ**（リステリア）、**生ハム**に注意。**水銀**の多い魚（キンメダイなど）は量に注意。
- **お酒、タバコ**は避ける。

## 産後

産後は、**うれしさと同時に、不安や疲れ**で心も体も不安定になります。

- **産後2週間以内**の強い出血、悪臭のあるおりもの、発熱：**感染症、子宮の中に胎盤が残る**など。連絡。
- **大量の出血**（1時間にナプキンを1枚以上替える、血の塊）：**産後出血**。救急。
- **片足の腫れ・痛み、息苦しさ、胸の痛み**：**血栓症**。
- **乳房の痛み、赤み、熱、発熱**：**乳腺炎**。
- **産後うつ**：産後2〜4週で、**気分が落ち込む、何も楽しめない、眠れない、赤ちゃんをかわいく思えない、自分を責める、自分や赤ちゃんを傷つけたい気持ち**。**10人に1人程度**に起こるとされ、**恥ずかしいことではなく、治療で良くなる**。保健師・産婦人科・小児科・心療内科・精神科に相談（第11章）。自治体の**産後ケア事業**もある。

## 避妊と性

- **緊急避妊**（避妊の失敗、性被害の後）：**72時間以内（できるだけ早く）**に医療機関へ。**産婦人科、薬局**（一部。2026年時点で運用が拡大中）。
- **性感染症**の検査は、保健所で無料・匿名のことがある。
