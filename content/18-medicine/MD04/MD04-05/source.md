# 胸やけ・飲み込みにくさ・黄疸

## 胸やけ・胃の不調

胸やけ、みぞおちの痛み、胃もたれ、げっぷは、多くは**逆流性食道炎**や**機能性ディスペプシア**など、治療できる良性の病気です。まず次の**警告症状**がないか確認します。

### 内視鏡検査を急ぎたい警告症状

- **飲み込みにくい、食べ物がつかえる**（食道がん、食道の狭窄）
- **体重が減っている**（意図せず）
- **吐血、黒い便**
- **貧血**
- **繰り返す嘔吐**
- **50歳以上で初めて**出た胃の症状
- 家族に胃がん・食道がんの人がいる

上記がある場合は、**早めに消化器内科を受診**し、内視鏡検査を受けてください。

### 救急車（119）を考えるサイン

- 胸やけやみぞおちの痛みに、**冷や汗、息苦しさ**（心筋梗塞のことがある）
- **突然の激しい上腹部痛、お腹が硬い**（穿孔）
- **吐血、タール便**

### どんな病気が隠れているか

| 病気 | 特徴 |
|---|---|
| **逆流性食道炎** | 胃酸が食道に逆流。胸やけ、酸っぱいものが上がる、咳、のどの違和感。食後・就寝時に悪化。肥満、食べ過ぎ、脂肪、飲酒が悪化させる |
| **機能性ディスペプシア** | 検査で異常がないのに、胃もたれ、膨満感、みぞおちの痛み。ストレス、胃の動きの低下 |
| **胃・十二指腸潰瘍** | 空腹時や夜間の痛み。**ピロリ菌**と**痛み止め**が原因。除菌で再発を減らせる |
| **ピロリ菌感染** | 胃がんの最大の原因。感染していれば除菌が勧められる |
| **食道がん** | 飲み込みにくい。喫煙と飲酒が危険因子 |

### 自宅でできること

- 食べ過ぎない、就寝の2〜3時間前は食べない。
- 脂肪の多い食事、アルコール、カフェイン、喫煙を控える。
- 就寝時に上半身を少し高くする。
- 市販の胃薬（制酸薬、H2ブロッカー）で改善しても、**繰り返す場合は受診**。

## 食べ物が詰まった・異物を飲み込んだ

- **魚の骨、薬のシート（PTP）、硬いもの**が引っかかると、食道を傷つけることがある。無理に飲み込んだり、ご飯を丸のみして押し込んだりしない。
- **痛い、つかえる、唾液が飲めない**場合は、耳鼻咽喉科・消化器内科を受診。
- **息ができない場合は窒息**です（第12章）。

## 黄疸（皮膚や白目が黄色い）

**黄疸**は、血液中のビリルビンという黄色い色素が増えて起こります。次の組み合わせに注意します。

- **皮膚や白目が黄色い**、**尿が濃い茶色**、**便が白っぽい**、かゆみ

### 救急車（119）・当日受診

- 黄疸に、**発熱、右上腹部の痛み、悪寒**（胆管炎）
- 黄疸に、**意識がもうろうとする**（劇症肝炎、肝性脳症）
- 吐血、タール便

### 原因

- **肝炎**（ウイルス：A型、B型、C型、E型。アルコール、薬）
- **胆石、胆管炎、膵頭部がん、胆管がん**（胆汁が流れない）
- **溶血性貧血**

### 肝臓は「沈黙の臓器」

肝臓は、かなり悪くなるまで症状が出ません。**倦怠感、食欲低下、むくみ**などが出る頃には進行していることがあります。

- **B型・C型肝炎ウイルス検査**は、**一生に一度は受けておく**ことが勧められています（自治体や職場の健診で無料・低額のことがある）。C型は飲み薬で治せ、B型もコントロールできます。
- **脂肪肝**（肥満、糖尿病、飲酒）は、放置すると肝硬変や肝がんに進むことがある。
- **アルコール**は、量と頻度に注意（第13章）。
