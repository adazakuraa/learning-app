# 腹痛

腹痛の大半は胃腸炎や便秘などの軽いものです。一方で、**数時間で手術が必要になる「急性腹症」**が含まれます。判断のポイントは、**突然始まったか、強さ、お腹の硬さ、全身の状態**です。

## 救急車（119）を考えるサイン

- **突然始まった激しい腹痛**（じっとしていられない、息もできないほど）
- **お腹が板のように硬い**、動くと響く、咳やジャンプで痛む（腹膜炎のサイン）
- **顔色が悪い、冷や汗、ぐったり**、脈が速い、ふらつく（ショック）
- **吐血、黒いタール状の便、大量の血便**
- 腹痛と**嘔吐が続き、お腹が張って、便もおならも出ない**（腸閉塞）
- 腹痛に**高熱、悪寒**、黄疸、右上腹部の痛み（胆管炎）
- **妊娠の可能性がある女性**の下腹部痛に、不正出血、めまい、失神（子宮外妊娠）
- **背中や腰に広がる**激痛、突然の裂けるような痛み（大動脈瘤・大動脈解離）
- 胸痛や冷や汗を伴う上腹部の痛み（心筋梗塞のことがある）
- 外傷（転倒、事故）の後の腹痛
- 乳児・幼児が**周期的に激しく泣き**、嘔吐やいちごジャム状の血便（腸重積）

## 今日中に受診したいサイン

- 痛みが**数時間以上続く、強くなっていく**
- 発熱を伴う
- **右下腹部**に痛みが移ってきた（虫垂炎）
- 食べ物や飲み物が受けつけない
- 高齢者、糖尿病、免疫を抑える薬を使っている人、妊娠中
- 以前からない痛みが**繰り返す**

## 様子を見てもよい腹痛

- 下痢や吐き気を伴い、**痛みが波のように来て、排便で楽になる**（胃腸炎）
- 軽い痛みで食事ができる、元気がある
- 月経に伴う痛みで、いつもの範囲

## 痛む場所別に考える病気

| 場所 | 考えること |
|---|---|
| **みぞおち** | 胃炎、胃・十二指腸潰瘍、**膵炎**（背中に抜ける、飲酒後）、**心筋梗塞** |
| **右上腹部** | **胆石、胆嚢炎、胆管炎**、肝炎。脂っこい食事の後が典型 |
| **右下腹部** | **虫垂炎（盲腸）**、卵巣の病気、子宮外妊娠、腸炎 |
| **左下腹部** | 便秘、憩室炎、腸炎 |
| **下腹部（中央）** | 膀胱炎、子宮・卵巣の病気 |
| **側腹部〜背中** | **尿管結石**（波のある激痛、血尿）、腎盂腎炎（発熱）。解離性大動脈瘤は鑑別が必要 |
| **お腹全体** | 腸閉塞、腹膜炎、腸炎 |

### 虫垂炎のたとえ話

典型的には、最初に**みぞおちや、へその周りがなんとなく痛み**、数時間〜半日で**右下腹部**にはっきりした痛みが移ってきます。**歩くと響く、軽く飛び跳ねると痛い**、吐き気や微熱があれば、受診してください。放置すると破れて腹膜炎になります。

## 受診までにできること

- **楽な姿勢**で安静にする（膝を曲げると楽なことが多い）。
- **食べない**。水分は、吐き気がなければ少量ずつ。
- **自己判断で下剤や浣腸を使わない**（腸閉塞や虫垂炎で悪化することがある）。
- 痛み止めは、強い痛みの場合に自己判断で飲み続けず、受診して診断を受ける。
- 受診時に、**痛みの場所と始まり方、最終の食事・排便、吐いたか、妊娠の可能性**を伝える。
