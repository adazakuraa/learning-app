# 一神教と多神教

- 宗教の根本的な違いの一つが「神が一人か複数か」です。
- **一神教**は「神はただ一人だけ存在する」という信仰で、ユダヤ教・キリスト教・イスラム教が代表例です。
    - この三つは実は同じ神（アブラハムの神）を信仰しています。
- 一神教では「唯一の真の神以外を崇めてはならない」という排他性が強く出やすく、これが他宗教との対立を生む一因になります。

- **多神教**は複数の神を認める信仰で、ヒンドゥー教・古代ギリシャ・ローマ・日本の神道などが代表例です。
- 多神教は「他の神も存在してよい」という発想なので、一般的に宗教間の対立が起きにくい傾向があります。
    - 日本人が神社にもお寺にも行くのは、多神教的な感覚の表れです。
- **仏教**はこの分類に当てはまらず、特定の「神」を崇拝するというより、悟りや解脱を目指す「教え」の体系として独自の位置を占めます。

## 神の数のちがいは、何につながるか

| | 一神教 | 多神教 |
|---|---|---|
| 神と世界 | 神は世界をつくった唯一の存在。人間は神に従う立場 | 自然のあちこちに神がいる。神々といっしょに世界がある |
| 教えの中心 | 聖典の教え（教義）を正しく信じることが大切 | 祭り・儀式・習慣など「行うこと」が中心 |
| ほかの宗教 | ほかの神を認めにくい。布教・改宗が大切にされる | ほかの神も取り入れやすい。神仏習合のように混ざり合う |
| 世界の見方 | 始まりと終わりがある直線的な歴史。最後の審判 | 季節のようにくり返す世界（循環）。輪廻の考え方も |

- ただし、これは大まかな傾向にすぎません。多神教の社会でも争いはありましたし、一神教の国にもほかの宗教に寛容な時代がありました（例：イスラム支配下のスペイン）。ちがいを単純に善悪で語らないことが大切です。
