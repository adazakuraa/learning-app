# 感情・状態を表す形容詞

- **ポジティブ**な感情：
    - happy / cheerful / delighted（嬉しい・陽気な・大喜びの）
    - excited /thrilled（わくわくしている・興奮している）
    - proud / satisfied / relieved（誇りに思う・満足した・ほっとした）
    - calm /relaxed / content（落ち着いた・リラックスした・満足した）
- **ネガティブ**な感情：
    - sad / upset / disappointed（悲しい・動揺した・失望した）
    - anxious / nervous /stressed（不安な・緊張した・ストレスを感じている）
    - angry / frustrated / irritated（怒っている・いらいらした・むかついた）
    - exhausted / drained /overwhelmed（へとへとな・疲れ果てた・キャパオーバーな）
- **状態**を表す形容詞：
    - confused（混乱している） surprised / shocked（驚いた / 衝撃を受けた）
    - embarrassed（恥ずかしい）
    - bored（退屈な）
    - lonely（孤独な）
    - motivated（やる気がある）
