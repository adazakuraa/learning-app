# 酸化と還元

- **酸化**とは酸素と結びつくことです。身近な酸化の例を以下に示します。
    - 鉄が錆びる：Fe + O₂ → Fe₂O₃（酸化鉄）
    - 有機物が燃える：C + O₂ → CO₂
    - リンゴが褐変する：切り口のポリフェノールが空気中の酸素で酸化
- **燃焼**は急速な酸化反応です。ゆっくりした酸化（**錆び**）と、速い酸化（燃焼）は、本質的に同じ反応です。
    - 使い捨てカイロは、袋に入っている鉄が空気に触れて酸化反応を起こすことで発熱しています。
- 酸化の逆で、酸素を失うことを**還元**と呼びます。
    - 酸化と還元は必ず同時に起きます（一方が酸化されると他方が還元される）。
- 還元の身近な例は金属の製錬です。鉄鉱石（酸化鉄）をコークス（炭素）と一緒に高温で熱すると、炭素が酸素を奪って（還元して）鉄が取り出せます。
    - 2Fe₂O₃ + 3C → 4Fe + 3CO₂
