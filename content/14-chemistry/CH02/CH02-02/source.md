# 元素と周期表

- **元素**とは原子の種類のことです。現在、118種類の元素が発見されており、それを整理した表が**周期表**です。
    - 縦の列を「族」、横の行を「周期」と呼びます。
- 覚えておくと良い主要元素を以下にまとめます。
    
    
    | 元素記号 | 元素名 | 補足 |
    | --- | --- | --- |
    | H | 水素 | 最も軽い |
    | C | 炭素 |  |
    | N | 窒素 | 空気の約78% |
    | O | 酸素 | 空気の約21% |
    | Na | ナトリウム | 金属 |
    | Mg | マグネシウム | 金属 |
    | Al | アルミニウム | 金属 |
    | Cl | 塩素 | 気体 |
    | Fe | 鉄 | 金属 |
    | Cu | 銅 | 金属 |
