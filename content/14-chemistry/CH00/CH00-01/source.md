# 化学とは・学ぶ意味

## この科目の概要

化学では、物質が何からできていて、どのように変化するのかを、原子・分子のレベルから学びます。

## この科目で学ぶこと

| 章 | 内容 |
|---|---|
| 第1章 | 化学とは何か |
| 第2章 | 原子・分子・元素 |
| 第3章 | 化学変化のしくみ |
| 第4章 | なぜ反応は起きるのか |
| 第5章 | 水溶液と身近な化学 |
| 第6章 | 身近な物質の化学 |
| 第7章 | 様々な元素の特徴 |

## 学ぶ意味

### 身近なものの正体がわかる

料理、洗剤、薬、プラスチック。身の回りのものは、すべて化学物質でできています。

### 安全に暮らせる

「混ぜるな危険」の理由や、さびや燃焼の仕組みを知ると、家庭の事故を防げます。

### 環境問題を理解できる

地球温暖化やプラスチックごみ、オゾン層。環境の問題は、化学の知識で理解が深まります。

## こんなときに役立つ

- 洗剤や薬を正しく使うとき
- 料理の変化（焦げる・ふくらむ）を理解したいとき
- 環境やエネルギーのニュースを見るとき

## 学び方のコツ

- 化学式は、**身近な物質から**覚える
- 「なぜ反応するのか」をイメージする
