# 差入保証金と支払手数料

## まず覚えること

- 建物を借りるときの**敷金** → **差入保証金**（資産）。退去時に戻ってくるお金だから。
- 不動産会社への**仲介手数料** → **支払手数料**（費用）。
- 家賃 → **支払家賃**（費用）。

## なぜ敷金は資産なのか

敷金は、部屋を借りるときに大家さんに預けるお金で、**退去するときに返してもらえます**（修繕費などを差し引かれることはあります）。戻ってくる権利なので資産です。

## 仕訳の例

**店舗を借りる契約をし、1か月分の家賃100,000円、敷金200,000円、不動産会社への仲介手数料100,000円を普通預金から支払った**

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 支払家賃 | 100,000 | 普通預金 | 400,000 |
| 差入保証金 | 200,000 |  |  |
| 支払手数料 | 100,000 |  |  |

**店舗を退去し、敷金200,000円のうち、修繕費30,000円を差し引かれた残額が普通預金に返金された**

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 普通預金 | 170,000 | 差入保証金 | 200,000 |
| 修繕費 | 30,000 |  |  |

## 土地を買ったときの手数料との違い

土地や建物を**買ったとき**の仲介手数料は、支払手数料ではなく、**土地・建物の金額に含めます**（付随費用：第6章）。

| 場面 | 仲介手数料の科目 |
|---|---|
| 部屋を**借りる** | 支払手数料（費用） |
| 土地・建物を**買う** | 土地・建物に含める（資産） |

## 覚え方のコツ

- 「**戻ってくるお金は資産（差入保証金）、戻ってこないお金は費用**」。
