# 給料の支払い（預り金・立替金・法定福利費）

## まず覚えること

- 給料から差し引いて会社が預かる**所得税・住民税・社会保険料** → **預り金**（負債）。「所得税預り金」「社会保険料預り金」のように分けることも多い。
- 社員の私的な支払いを会社が立て替えた → **従業員立替金**（資産）。
- 社会保険料の**会社負担分** → **法定福利費**（費用）。

## なぜ「預り金」なのか

会社は、社員の給料から所得税や社会保険料を**差し引いて（天引きして）**、社員の代わりに国や年金事務所に納めます。差し引いた時点では、まだ納めていないので、会社が**一時的に預かっているお金**です。後で納める義務があるので負債になります。

## 仕訳の例

**給料300,000円の支払いにあたり、所得税20,000円と社会保険料40,000円を差し引き、残額を普通預金から支払った**

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 給料 | 300,000 | 所得税預り金 | 20,000 |
|  |  | 社会保険料預り金 | 40,000 |
|  |  | 普通預金 | 240,000 |

- 給料（費用）は**総額の300,000円**
- 社員が受け取るのは差し引き後の240,000円

**預かっていた所得税20,000円を、税務署に現金で納付した**

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 所得税預り金 | 20,000 | 現金 | 20,000 |

**社会保険料を納付した。社員から預かった40,000円と、会社負担分40,000円の合計80,000円を普通預金から支払った**

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 社会保険料預り金 | 40,000 | 普通預金 | 80,000 |
| 法定福利費 | 40,000 |  |  |

> 社会保険料は、**会社と社員が半分ずつ**負担します。会社負担分は会社の費用（法定福利費）です。

## 立替金

**社員が個人的に負担すべき保険料5,000円を、会社が現金で立て替えた**

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 従業員立替金 | 5,000 | 現金 | 5,000 |

**給料支払いのとき、上の立替金を差し引いた**

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 給料 | 250,000 | 従業員立替金 | 5,000 |
|  |  | 普通預金 | 245,000 |

## 覚え方のコツ

- 給料の仕訳は「**左に給料の総額、右に差し引いたもの＋手取り**」。
- 「預り金は後で払う（負債）、立替金は後でもらう（資産）」。
