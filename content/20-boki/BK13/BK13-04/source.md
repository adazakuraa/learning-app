# 第3問（決算）攻略

## まず覚えること

- 第3問（35点）は、**決算整理前残高試算表＋決算整理事項 → 精算表・財務諸表・決算整理後残高試算表**。
- 手順：**① 決算整理事項をすべて仕訳 → ② 試算表の金額に足し引き → ③ 解答欄に記入 → ④ 当期純利益を確認**。
- **部分点がある**ので、1つの整理事項で止まらず、できるものから埋める。

## 解く手順

![第3問の手順](dai3.svg)

### ① 決算整理仕訳を下書きする

問題文の決算整理事項を、上から順に仕訳します（BK11の8つの事項）。

- 現金過不足・仮払金・仮受金の整理
- 貸倒引当金（**差額補充法**：必要額 − 残高）
- 売上原価（**しくり・くりし**）
- 減価償却（**月割**に注意）
- 貯蔵品・経過勘定（**タイムライン**で月数を数える）
- 消費税（仮受 − 仮払）
- 法人税等（**最後**に）

### ② 試算表の金額に足し引きする

問題用紙の決算整理前残高試算表の横に、**整理仕訳の金額を直接書き込む**と速いです。

### ③ 解答欄に書く

- 財務諸表なら**表示名**に注意（売上高・売上原価・商品・前払費用など）。
- 貸倒引当金・減価償却累計額は**資産から差し引く**。

### ④ 当期純利益を確かめる

損益計算書の当期純利益と、貸借対照表の繰越利益剰余金の増加分が一致するか確認します。

## よくある失点

| 失点の原因 | 対策 |
|---|---|
| 期中取得の固定資産を12か月で償却 | 試算表の注記・問題文の日付をチェック |
| 売上原価で期首と期末を逆に | 「整理前の繰越商品＝期首」 |
| 貸倒引当金を全額繰り入れ | 「必要額 − 残高」 |
| 経過勘定の月数違い | 必ず線を描く |
| 繰越利益剰余金に利益を足し忘れ | B/Sの最後に確認 |

## 最後に

第3問は**同じパターンの繰り返し**です。過去問を5回分解けば、ほとんどの整理事項に慣れます。この科目の第11・12章を何度も見直して、**8つの決算整理を自分で説明できる**ようになれば、合格はすぐそこです。
