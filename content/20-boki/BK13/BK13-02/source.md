# 第1問（仕訳）攻略

## まず覚えること

- 勘定科目は**選択肢の中から選ぶ**。選択肢にない科目は使えないので、**選択肢をヒント**にする。
- 解き方：**① 取引を読んで登場する科目を探す → ② 5要素と増減を判断 → ③ 金額を計算 → ④ 左右の合計を確認**。
- 頻出パターンを覚えておけば、半分以上は即答できる。

## 頻出パターン（確認用）

| 取引 | 仕訳のポイント |
|---|---|
| 他人振出小切手を受け取った | 現金 |
| 小切手を振り出した | 当座預金の減少 |
| 商品を掛けで売り、送料を払った | 売掛金・売上、発送費 |
| 手付金を払った／受け取った | 前払金／前受金 |
| クレジット払いで売った | クレジット売掛金・支払手数料 |
| 商品券を受け取った | 受取商品券 |
| 備品を後払いで買った | 備品・**未払金** |
| 土地を買った（手数料あり） | 土地に手数料を**含める** |
| 固定資産を売った | 累計額・売却損益（**差額で出す**） |
| 給料を支払った | 給料（総額）・預り金・普通預金 |
| 社会保険料を納付した | 預り金・**法定福利費** |
| 株式を発行した | 資本金 |
| 配当が決まった | 繰越利益剰余金・未払配当金・利益準備金 |
| 法人税等の中間納付 | 仮払法人税等 |
| 前期の売掛金が貸倒れ | **貸倒引当金**（足りなければ貸倒損失） |
| 現金過不足の原因判明 | 現金過不足を消す |
| 出張旅費の精算 | 仮払金を消す |
| 内容不明の入金 | 仮受金 |
| 電子記録債権の発生記録 | 売掛金 → 電子記録債権 |

## ひっかけに注意

- 「**当社負担**」か「**先方負担**」か（諸掛り）。
- 「**前期**に発生した」か「**当期**に発生した」か（貸倒れ）。
- 「**商品**」か「**商品以外**」か（売掛金・買掛金 vs 未収入金・未払金）。
- 「**自社振出**」か「**他社振出**」か（小切手）。
- 利息は**月割**（○か月分）。

## 練習のしかた

- 問題を見て、**10秒以内に科目が浮かぶか**をチェック。浮かばない取引を重点的に復習。
- 金額の計算は、**電卓を使って2回**確かめる。
