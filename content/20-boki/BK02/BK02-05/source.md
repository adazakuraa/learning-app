# 小口現金

## まず覚えること

- **小口現金**：交通費や文房具代など、少額の支払いのために**担当者（小口係）に渡しておく現金**。資産。
- **定額資金前渡法（インプレスト・システム）**：毎週・毎月、一定額を渡しておき、**使った分だけ補給**する。
- 会計係は、小口係から**報告を受けたときに費用を計上**する。

## なぜこの仕組みがあるのか

切手代や電車代のような小さな支払いのたびに、会計係が現金を出して記録するのは大変です。そこで、**一定額をまとめて担当者に渡し、使い道は後でまとめて報告してもらう**ようにしました。

## 仕訳の流れ

**① 小口現金として、小切手30,000円を振り出して小口係に渡した**

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 小口現金 | 30,000 | 当座預金 | 30,000 |

**② 小口係から、今週の支払いの報告を受けた：交通費8,000円、消耗品費5,000円、通信費2,000円**

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 旅費交通費 | 8,000 | 小口現金 | 15,000 |
| 消耗品費 | 5,000 |  |  |
| 通信費 | 2,000 |  |  |

**③ 使った分の15,000円を、小切手を振り出して補給した**

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 小口現金 | 15,000 | 当座預金 | 15,000 |

これで小口現金は、また30,000円に戻ります。

### 報告と同時に補給した場合

②と③が同時なら、小口現金の増減が相殺されるので、まとめて書けます。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 旅費交通費 | 8,000 | 当座預金 | 15,000 |
| 消耗品費 | 5,000 |  |  |
| 通信費 | 2,000 |  |  |

## 覚え方のコツ

- **費用を計上するのは「報告を受けたとき」**（小口係が支払ったときではない）。会計係が知った時点で記録する、と考えます。
- 「渡す → 報告 → 補給」の3ステップ。補給額 ＝ 使った額。
