# 試算表のしくみ

## まず覚えること

- **試算表（T/B）**：総勘定元帳の各勘定の金額を1つの表に集めたもの。**転記が正しいか**を確かめる。
- 3種類：**合計試算表**（借方合計・貸方合計）、**残高試算表**（残高だけ）、**合計残高試算表**（両方）。
- 借方の合計と貸方の合計は**必ず一致**する。一致しなければ、どこかで間違えている。

## なぜ左右が一致するのか

すべての仕訳は、左右の金額が同じです。それを勘定に写しただけなので、**全部の勘定の左の合計 ＝ 全部の勘定の右の合計**になります。

## 残高試算表の例

| 借方残高 | 勘定科目 | 貸方残高 |
|--:|---|--:|
| 70,000 | 現金 | |
| 150,000 | 売掛金 | |
| 200,000 | 備品 | |
| | 買掛金 | 90,000 |
| | 資本金 | 250,000 |
| | 売上 | 300,000 |
| 180,000 | 仕入 | |
| 40,000 | 給料 | |
| **640,000** | 合計 | **640,000** |

- 資産・費用は**借方**に残高、負債・純資産・収益は**貸方**に残高が出ます（ホームポジションのとおり）。

## 試算表で見つけられない誤り

左右の合計が一致していても、次のような誤りは見つけられません。

- 仕訳そのものを**忘れた**、**二重に**転記した
- **左右とも同じ金額**で間違えた
- **勘定科目を間違えた**（例：売掛金を受取手形に転記）
- 借方と貸方を**逆に**転記した

## 覚え方のコツ

- 「**試算表は、転記ミスの検査表**」。
- 残高の位置はホームポジションと同じ。迷ったら5要素の表を思い出す。
