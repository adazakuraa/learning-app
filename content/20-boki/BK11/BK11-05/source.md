# 減価償却・消費税・法人税等の決算整理

## まず覚えること

- **減価償却**：（取得原価 − 残存価額）÷ 耐用年数 × 月数/12。間接法で累計額を計上（BK06-02）。
- **消費税**：仮受消費税 − 仮払消費税 ＝ **未払消費税**（BK07-04）。
- **法人税等**：当期の税額を法人税等にし、仮払法人税等との差額を **未払法人税等**（BK07-03）。

## 減価償却（決算整理として）

**建物：取得原価3,000,000円、残存価額ゼロ、耐用年数30年。備品：取得原価360,000円、残存価額ゼロ、耐用年数5年（当期の12月1日に取得、決算日3月31日）**

- 建物 ＝ 3,000,000 ÷ 30 ＝ **100,000円**
- 備品 ＝ 360,000 ÷ 5 × 4/12 ＝ **24,000円**（12月〜3月の4か月分）

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 減価償却費 | 124,000 | 建物減価償却累計額 | 100,000 |
|  |  | 備品減価償却累計額 | 24,000 |

> **期中に取得した資産は月割**。決算整理前の試算表に「当期取得」と書いてある資産を見落とさないようにしましょう。

## 消費税

**仮払消費税80,000円、仮受消費税150,000円**

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 仮受消費税 | 150,000 | 仮払消費税 | 80,000 |
|  |  | 未払消費税 | 70,000 |

## 法人税等

**税引前当期純利益に対して法人税等400,000円を計上する。中間納付額（仮払法人税等）は150,000円**

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 法人税等 | 400,000 | 仮払法人税等 | 150,000 |
|  |  | 未払法人税等 | 250,000 |

> 法人税等は**最後に**計算します。問題で「税引前当期純利益の30％」とあれば、他の決算整理をすべて終えてから利益を計算し、その30％を求めます。
