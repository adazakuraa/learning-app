# 損益計算書と貸借対照表の作成

## まず覚えること

- 財務諸表では、勘定科目名と**表示名が違う**ものがある：**売上 → 売上高、仕入 → 売上原価、繰越商品 → 商品**、前払保険料など → **前払費用**、未払利息など → **未払費用**。
- **貸倒引当金・減価償却累計額**は、対応する資産から**差し引く形**で表示する。
- 貸借対照表の**繰越利益剰余金 ＝ 決算整理前の残高 ＋ 当期純利益**。

- 売掛金500,000から貸倒引当金10,000を差し引いて、**490,000**と表示します。
- 繰越利益剰余金は、前期からの残高57,000に当期純利益51,800を足した**108,800**（例）。

## なぜ表示名を変えるのか

財務諸表は、会社の外の人（銀行や投資家）が読む報告書です。「仕入」より「売上原価」、「繰越商品」より「商品」の方が、**内容がわかりやすい**からです。

## よくあるミス

- 損益計算書に「仕入」と書く → **売上原価**。
- 繰越利益剰余金に当期純利益を**足し忘れる**。
- 貸倒引当金を負債の側に書く → **資産から差し引く**。
