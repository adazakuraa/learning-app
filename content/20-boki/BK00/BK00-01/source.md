# 簿記3級とは・学ぶ意味

## この科目の概要

簿記3級は、日商簿記検定3級の合格を目標に、会社のお金とモノの動きを記録するルールと、決算書を作るまでの流れを学ぶ科目です。

## この科目で学ぶこと

| 章 | 内容 |
|---|---|
| 第1章 | 簿記の基本 |
| 第2章 | 現金と預金 |
| 第3章 | 商品売買 |
| 第4章 | 手形と電子記録債権 |
| 第5章 | いろいろな債権・債務 |
| 第6章 | 固定資産 |
| 第7章 | 株式会社と税金 |
| 第8章 | 帳簿 |
| 第9章 | 伝票と証ひょう |
| 第10章 | 試算表 |
| 第11章 | 決算整理 |
| 第12章 | 精算表と財務諸表 |
| 第13章 | 試験対策 |

## 学ぶ意味

### 資格として役立つ

簿記3級は、経理・事務の仕事はもちろん、就職や転職でも評価される、知名度の高い資格です。

### 会社のお金の流れがわかる

貸借対照表と損益計算書が読めると、会社がもうかっているか、安全かが判断できるようになります。

### 自分のお金の管理にも使える

資産と負債、収入と費用で考えるくせがつくと、家計や副業、確定申告にも役立ちます。

## こんなときに役立つ

- 経理・事務の仕事をするとき
- 取引先や投資先の会社の決算書を見るとき
- 副業やフリーランスで帳簿をつけるとき

## 学び方のコツ

- **仕訳を毎日解く**（試験の45点は仕訳）
- 決算整理の8つを、自分で説明できるようにする
