# 現金出納帳・仕入帳・売上帳

## まず覚えること

- **現金出納帳**：現金の入金・出金・残高を、日付順に記録する。
- **仕入帳・売上帳**：取引先・品名・数量・単価・金額を記録する。**返品は赤字（試験では区別して記入）で差し引く**。
- 帳簿の最後で、**総仕入高 − 仕入戻し ＝ 純仕入高**、**総売上高 − 売上戻り ＝ 純売上高** を計算する。

## 現金出納帳

| 日付 | 摘要 | 収入 | 支出 | 残高 |
|---|---|--:|--:|--:|
| 4/1 | 前月繰越 | 50,000 | | 50,000 |
| 4/3 | A社へ売上（現金） | 30,000 | | 80,000 |
| 4/8 | 文房具代 | | 2,000 | 78,000 |
| 4/20 | B社へ買掛金支払 | | 40,000 | 38,000 |

収入の合計 − 支出の合計 ＝ 残高。**総勘定元帳の現金勘定の残高と一致**します。当座預金出納帳も同じ形です。

## 仕入帳

| 日付 | 摘要 | | 金額 |
|---|---|---|--:|
| 4/5 | C商店　掛け | 商品X 10個 @1,000 | 10,000 |
| 4/9 | C商店　掛け返品 | 商品X 2個 @1,000 | （2,000） |
| 4/30 | | 総仕入高 | 10,000 |
| | | 仕入戻し高 | 2,000 |
| | | **純仕入高** | **8,000** |

売上帳も同じ形で、「総売上高 − 売上戻り高 ＝ 純売上高」を計算します。

## 仕入諸掛があるとき

当社負担の引取運賃は仕入原価に含めるので、**仕入帳にも運賃を記入**し、仕入金額に含めます。

## よくあるミス

- 返品を足してしまう → 返品は**差し引く**。
- 純仕入高・純売上高を、総額のまま答えてしまう。
