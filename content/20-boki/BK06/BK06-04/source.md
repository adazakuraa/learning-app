# 修繕費と資本的支出

## まず覚えること

- 壊れたところを**元に戻す**修理 → **修繕費**（費用）。
- 価値を**高める・使える期間を延ばす**改良 → **資本的支出**として、**建物などの資産に加える**。
- 両方を含む工事は、問題文の指示に従って金額を分ける。

## なぜ区別するのか

雨漏りを直すのは「元の状態に戻す」だけなので、その年の費用です。一方、建物に**エレベーターを付ける**ような改良は、建物の価値そのものを高め、何年も役に立ちます。これは減価償却と同じ考え方で、**資産に加えて、使う期間に分けて費用にします**。

## 仕訳の例

**建物の改修工事を行い、代金1,000,000円を普通預金から支払った。このうち700,000円は耐震補強（資本的支出）、残りは壁の塗り直し（修繕）である**

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 建物 | 700,000 | 普通預金 | 1,000,000 |
| 修繕費 | 300,000 |  |  |

## 見分け方

| 内容 | 処理 |
|---|---|
| 壊れた窓ガラスの交換、塗装の塗り直し、定期点検 | 修繕費（費用） |
| 増築、エレベーターの設置、耐震補強、用途変更の改装 | 資本的支出（建物などに加算） |

## 覚え方のコツ

- 「**元に戻す → 費用、パワーアップ → 資産**」。
