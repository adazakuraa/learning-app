# 解説動画 生成ガイドライン（全科目共通）

このファイルは、AI（Claude Code など）が単元の解説動画を作るときに必ず従う共通ルール。
科目ごとの指示は `content/<科目>/subject.yaml` の `generation`、単元ごとの指示は `unit.yaml` の `generation` に書く。
優先順位: 単元の指示 > 科目の指示 > このガイドライン（ただし「正確性」の項目は常に最優先）。

## 学習者と目的（すべての判断の前提）
- 学習者は中学レベルの知識も不確かな大人。小学校〜高校（一部大学）レベルの教養を、広く・本質的に理解することが目的。
- ゴールは暗記ではなく「イメージできる」「流れがわかる」「他の知識とつなげて考えられる」こと。
- その分野で重要な用語は出す。細かい専門用語・例外・細部は後回しにしてよい（元教材にある内容を否定・省略したことにはしない。動画で深追いしないだけで、テキストには残っている）。
- 前提知識（小学校・中学校レベルの算数や言葉）が必要なところは、短く補ってから進む。
- 理解のために必要だと判断した説明・たとえ・背景は追加してよい（下の「正確性」のルールに従う）。
- 他の単元・他の科目とのつながりがあれば一言触れる（例: 「これは化学の◯◯ともつながる」）。ただし教材に存在する内容に限る。
- 歴史など流れのある分野では、「なぜそうなったか（原因）」「その結果どうなったか」「今の私たちの社会とどうつながるか」を意識して、過去から今を考える視点（温故知新）を持てるようにする。

## 正確性（最優先）
- 元教材（source.md）の内容を正確に伝える。元教材と矛盾することを言わない。
- 元教材にない説明・例を加えてよいが、台本で `added: true` を付けて区別し、事実として確かなものだけにする。
- 数値・年号・人名・用語・式は元教材の表記に合わせる。
- 不確かな補足は入れない。迷ったら元教材の範囲にとどめる。

## わかりやすさ
- 文章の読み上げ動画にしない。図解・アニメーション・具体例で見せる。
- 専門用語は初出で言い換える。抽象的な概念には身近な具体例を付ける。
- 重要な概念は、最初に予告し、説明し、最後にまとめて繰り返す。
- 1画面に載せる文字は少なく（目安: 見出し1つ＋短い要点3つまで）。

## 字幕・音声
- 字幕は必ず付ける。音声がなくても字幕と画面だけで理解できる構成にする。
- 字幕は1行全角20字前後・最大2行、1枚あたり最低1.5秒以上表示する。
- 字幕と画面の内容を一致させる（話している内容が画面に出ている状態）。

## 構成（目安）
1. 導入: この単元で何がわかるようになるか（10〜20秒）
2. 本編: 元教材の順序に沿って、概念ごとに区切って説明
3. 問題がある単元: 問題を提示 → 考える時間（数秒の間）→ 解き方
4. まとめ: 重要ポイントの振り返り（20秒前後）
- 長さは内容に応じて 3〜10 分程度。無理に引き延ばさない。

## 表現方法（単元ごとに選ぶ・組み合わせ可）
- 基本は whiteboard。知識を板書のように順に整理していく（見出し → 要点 → 図・矢印で関係を整理）。
- イメージしやすさ・覚えやすさのために、図やアニメーションが役立つ場面では積極的に使う（文系科目でも同じ）。
  例: 分類はベン図や木構造、因果は矢印、時代の流れは年表、量の大小は棒や面積、仕組みや動きはアニメーション。
- slide（スライド解説型）: 重要な文・図表を順に提示し、キーワードを強調する
- animation（アニメーション型）: 動き・流れ・仕組みを視覚化する
- whiteboard（ホワイトボード型）: 図や式を順に書き足し、思考の過程を見せる
- auto: 内容に応じて上記から選ぶ（既定）
